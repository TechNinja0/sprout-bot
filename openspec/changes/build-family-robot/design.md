## Context

依据 docs/00—11、两份调研、动态预览与采购文档。Word 是对应 Markdown 的排版副本；历史 ZIP 不作为现行规格。仓库无代码、无 Git、无已有 OpenSpec。已发现华为 OXF-AN10/API 31，电脑 macOS arm64/32 GB，JDK17、Android SDK36、AGP8.10.1、Gradle8.11.1 可用。当前阶段由探索自动转入提案与实施，用户授权不逐项询问。

## Goals / Non-Goals

**Goals:** 交付桌面首版 P0 与可选 P1，包括真实语音、多轮、视觉、媒体、图书、家长管理、本地约束；同一 APK 两种身份，服务端独立启动；建立可重跑的测试、部署维护和开源基础。docs 的每项约束映射到任务与验收。

**Non-Goals:** 不擅自购买硬件、发布公网仓库、抓取商业书库或开启外部模型。自动翻页跟读、声音克隆、多家庭多人、公网远程和实际电机机构为文档已有后置范围。运动项目提供独立协议和安全逻辑，不宣称通过机械实测。

## Decisions

1. 项目为 `android-app/`、`ai-service/`、`motion-firmware/`，共享 `protocol/` 与 `docs/engineering/`。Kotlin/Compose 单 APK、AGP8.10.1/Gradle8.11.1/JDK17/minSdk29/compileSdk36，标准 debug 测试签名；不依赖公司私有组件、统计 SDK、ARouter 或企业签名。本次为新开源工程，android-build 技能的企业 releaseForDev/KMP 模板不适用。
2. Python3.12/FastAPI/Pydantic/SQLite WAL，资源文件存专用数据目录；REST 管理和有界轮询控制，长 AI 作业不占控制事务。SQLite 原子事务保证发布/版本，后台作业持久状态和有限并发。先不用 Redis、向量库和多微服务。
3. 部署初始化生成自签 TLS 证书、服务 ID 和本地管理员恢复材料，私钥与令牌不入 Git。通过线下服务连接材料固定证书 SHA256；HTTPS 校验精确 pin 而非信任任意证书。两分钟单次机器人登记/家长配对材料，后者需机器人本地确认。令牌哈希保存、权限绑定服务器身份，不用昵称授权。
4. 配置 expectedVersion 乐观锁，机器人在线才接受控制，短 TTL，机器人应用 ACK 才标记成功。掉线的请求过期，不重连重放。配置保存与紧急停止本地优先。限制配置即时生效，声音/模型下一轮生效。
5. 资源使用不可变发布快照+可修改草稿。图片/PDF/TXT/Markdown 导入，按页保留源图与审核文本；OCR 输出只能成为草稿。顺序读取全本原文，检索仅选书；相同标题/版本歧义澄清。音频键包含正文、引擎、音色、速度、读音规则，完整音频+清单校验才离线就绪。
6. 语音采用 sherpa-onnx KWS/有限命令、单 AudioRecord+系统 AEC（验证支持），服务端本地 ASR/TTS，LLM/VLM 提供可配置本地适配器。具体权重先核实许可与实际下载，再固定清单；不以接口假实现代替模型。macOS 原生能力可作为明确标注的平台适配器，Linux 使用可选模型后端。
7. CameraX 无预览，仅保留最新一帧，只按视觉请求发送新图；结束会话丢弃，图片不落盘。Compose 参数脸继承原创设计，实际音频包络驱动嘴形。停止使 generation 失效，旧网络/模型结果不播放。
8. 时间配置选择 Asia/Shanghai，20:00—09:00 推荐模板，首次部署时明确为本轮推荐初值；每日额度默认关闭，媒体单次30分钟可配置，临时放行最长15分钟；姓名默认“小伙伴”，最终唤醒词随模型支持选择并在设置中可见。年龄基准5岁/2026-09-22（估算），英语固定零基础，主动邀请与计划默认关闭。
9. P1 提供受限小游戏、可选原创故事、最小使用摘要与有限视觉互动；不进行成绩或心理评价。长期记忆候选默认不使用，家长批准后使用，拒绝/删除传播到备份恢复边界。云端默认关闭，不在失败时自动开启。
10. 自有代码 MIT，原创示例文本标明来源；第三方依赖、模型权重、音色与素材单独登记。开源准备不等于自动公开发布。部署密钥、设备标识、家庭书籍和原始会话全部忽略。

## Risks / Trade-offs

- [儿童实际唤醒/声学不确定] → 成人/合成音仅验证链路，保留30次儿童唤醒、2小时背景声、双讲实测门槛。
- [仅一台手机] → 华为实测两身份，第二端用独立客户端验证协议；双真机跨端与家庭实体样书单列，不能伪造。
- [模型下载和内存] → 有界下载、固定版本/哈希、逐模型加载和超时，重任务不阻塞控制；缺模型显式不可用。
- [离线无法即时撤回] → 显示待同步，本地PIN可停用，重连优先撤回。
- [长时验收] → 4小时混合/24小时待机需真实计时，不压缩成单测；测试运行日志保存在不入库目录。
- [旧设计与代码并存] → 新增实现状态矩阵，历史文档不偷偷改为已完成。

## Migration Plan

全新安装，数据库带schema版本；初始化数据目录并记录服务身份，安装APK，可信注册配对，先使用原创样例验证，再由家长导入真实书籍。升级前备份数据库与原稿；回滚使用兼容旧版本和匹配备份，恢复资源为待审并保留删除墓碑，不恢复手机凭据。生产不运行测试后门。

## 实测后的实现决定（2026-09-23）

- Apple Silicon 使用可选 `mlx-whisper 0.4.3` 与固定8bit large-v3-turbo；30秒上限允许单窗口解码，让语言检测和转写复用一次音频编码。Silero VAD先过滤静音。跨平台默认保留 faster-whisper small CPU。
- 语音独立进程驻留、超时销毁重建；可选启动预热只用原创短句。普通回答确定性解码，默认中文，英语请求给简单英文加中文解释；昵称沿用配置，事实遵循孩子最新陈述。
- 服务端素材/派生音频默认10GiB软上限，保留256MiB磁盘空间；恢复失败回滚新增文件与数据库。手机完整缓存限制1GiB。模型下载、解包独立检查余量。
- 摘要只保存累计用量、内容类别和失败计数，明确离线同步及重新登记重置范围。静音、限时与故障采用不同纯脸状态；待机触摸行为以后续新需求为准。
- 真实4小时混合和24小时待机加周期会话分别计时，设置完成后才开始计时，保存源文件/安装包SHA256与温控、内存、音频记录。热状态框架注入和短时脚本冒烟不得当作真实长时/高温验收。

最初Kokoro方案曾采用实时语音与后台图书两个有界进程。新增Qwen方案调整为一个TTS进程复用模型，与ASR独立；后台合成占用时的实时响应需重新实测，不能沿用旧版“不占实时TTS”的结论。断网传输错误可使用完整哈希且版本一致的离线音频，HTTP拒绝与TLS错误不得触发回退。对话10分钟截止仅关闭问答和相机，媒体保持同一有效播放代际直到独立媒体上限。

单次发言遵循PRD的30秒上限，句末停顿1.2秒。手机使用本地Silero VAD，检测到发言即通知会话，避免等ASR请求发出时才续接。普通音量不作为发言依据。10分钟问答到期时关闭相机并取消旧结果，播放可立即取消、最多4秒的本地休息提示；媒体播放仍使用独立上限。

## 同仓库新增需求合并（2026-09-23）

用户在后续任务中明确选择Qwen3-TTS 1.7B、可替换TTS接口与语气控制，同时确认可听可见的唤醒/触摸反馈方案。上述新增要求纳入本次交付的第9阶段；界面和交互以 `docs/13-唤醒反馈与倾听交互设计.md`、语音部署以 `docs/engineering/本地语音合成.md` 为补充依据，不能把原版实现和验收直接视作新功能完成。

新资源发布快照固定渲染配置；旧图书已有音频保持原样，不以新引擎补齐旧版本的缺段，换声通过试听、重新发布和重新下载闭合。静态短提示预先生成并记录素材来源，家长改全局声音不自动替换APK内提示。语气指令不拼入原文正文，CustomVoice不扩展为声音克隆。

阅读进度回报与播放解耦：本地保存每资源最新待同步位置，单后台发送者、单次网络调用5秒上限，最多128项，超限显示诊断而不删除正文/音频。递增序号先持久保存，迟到确认仅移除相同序号。进度网络阻塞不应让已播完的音频仍处于播放状态，相关故障注入及清单自然结束须在合并版本重测。

## 原始诊断与隐私缺口收尾

第11节采用服务端白名单诊断、PIN管理页单一AudioInput有界自检、事件化单项记忆撤回、真实帧状态驱动相机短音。具体数据、取消和恢复边界见 `docs/engineering/诊断与记忆撤回实现说明.md`；不添加云端采集、后台录音或第二个AudioRecord，不将硬件链路通过等同儿童声学验收。
