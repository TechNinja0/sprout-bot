## Why

现有 docs 已明确家庭儿童陪伴、英语磨耳朵、看封面读书与家长控制，但仅有设计资料。需要实现可部署、可维护、可开源的桌面首版，并建立需求到真实验证的证据链。

## What Changes

- 新建独立 `android-app` 工程：同一 APK 的家长/机器人身份、纯表情、语音和视觉、播放、本地使用限制与管理。
- 新建独立 `ai-service` 工程：TLS 服务身份、设备登记和配对、配置确认、家庭资源库、导入/OCR、审核与版本、音频、检索、对话与记忆。
- 新建 `protocol` 契约与验收样例；`esp32-firmware` 保留独立运动安全契约和可运行本地安全逻辑测试，不把未连接机械硬件记为已验收。
- 提供部署、备份恢复、故障排查、维护、贡献、许可证与第三方组件/模型清单，准备公开发布所需文件，不自动向公网发布家庭内容或仓库。
- 用户授权本轮技术与未定产品选择采用推荐方案，阶段自动推进。真实儿童、实体样书、运动件以及长时验收缺少证据时保持待验，不能用模拟通过代替。

## Capabilities

### New Capabilities

- `device-trust`: 服务注册、短时配对、本机确认、权限、配置确认和恢复。
- `robot-session`: 唤醒、多轮、停止、相机、纯表情、音频生命周期与取消。
- `parent-policy`: 成长、英语、时间额度、声音、隐私、诊断与摘要。
- `resource-library`: 全类型资源、图书 OCR 校对发布、封面选书、朗读、离线和维护。
- `local-intelligence`: 本地 ASR/LLM/TTS/VLM、儿童策略、最小记忆与可选趣味互动。
- `delivery-maintenance`: 项目隔离、部署、开源材料、维护与可复现验收、运动扩展边界。

### Modified Capabilities

无现有 OpenSpec 规格。

## Impact

新增 Android/Kotlin/JVM、Python 与协议文件，原设计 Word/Excel/HTML 作为历史设计基线保留。测试目标为已连接华为 OXF-AN10（Android API 31）和当前 arm64 macOS 32 GB 家庭电脑；模型下载到不入库目录，权重许可独立登记。P0 和 P1 桌面软件纳入本变更；docs 明确后置的自动翻页、音色克隆、多家庭、远程公网、SLAM/自动回充与实际移动硬件留在路线图。
