## 1 产品定位已经收敛

为目前 5 岁、英语零基础的孩子制作家庭陪伴机器人，随成长调整表达与内容；以陪聊、趣味互动、故事和英语听力环境为主，识物为辅。安静陪伴是默认风格，家庭电脑常开可接受；家长在自己的 Android 手机上管理使用时段。

这是家庭自用产品，首版按一名孩子、一台机器人、一部主要家长手机设计；这是一种范围建议，不自动扩展到公共服务、多租户、儿童社交或学校课堂。两部手机同一个 APK，按身份加载不同模块。

已确认保留：纯表情、语音唤醒、多轮交流、相机随授权会话开启、30 秒续问、10 分钟问答上限。功能实施顺序以本轮场景为主：先聊天、故事、英语和管理，再丰富视觉和移动；不删除已有识物需求。

## 3 成长适配具体怎么做

### 3.1 年龄档案

家长填出生年月，或“当前年龄＋记录日期”；后者只有估算精度，界面要说明，不伪造精确生日。年龄由规则计算，不根据摄像头、声音推断。首版只需一个孩子档案，访客对话不自动改变主人档案。

建议的表达分段：5—6 岁用短句、具体事物、少量选择；7—8 岁逐渐增加因果、简单推理和共同创作；9 岁以后增加讨论和兴趣探索。这是产品初始配置，不是儿童能力诊断，也不保证与每个孩子一致。

年龄影响回答长度、词汇和推荐内容；角色名字、性格、声音不在生日当天突然改变。家长可选择偏简单/适中并覆盖推荐；年龄增长不自动扩大摄像头、云端、使用时间或内容授权范围。

### 3.2 英语零基础的体验

首版默认听为主：儿歌、童谣、生活短句、简单重复故事。优先清楚发音、熟悉主题和可重复内容；不默认考试、打分或要求孩子每句回应。短内容可以多次听，不以“完成很多新课”作为目标。

在允许时段，孩子可以说“听英文歌”，家长也可配置有限时长播放清单。主动播放默认关闭；设置英语计划需要家长单独启用，计划不得覆盖禁用时段和额度。错过的计划不在重启/重连后补播。

中文是可随时请求的解释方式；孩子说“听不懂”时简短中文解释，再给英语原句。是否每段附中文、口音和语速由家长试听选择。对中文问题不随机切成长篇英文；年龄增长不直接升级英语难度。

首版不做复杂自动能力评分。未来可以依据实际使用提出调整建议，由家长确认；不根据几次沉默推断听懂、不懂或能力差。英语环境是使用目标，不对学习效果作保证。

## 4 角色、记忆和家庭使用边界

### 4.1 角色规则

角色温和、安静、有好奇心，固定说话风格；回答先简短，孩子追问再展开。孩子难过时先回应感受，必要时建议找家长；不作心理诊断，不声称自己真的受伤、吃醋或需要孩子照料。不在孩子离开、休息或拒绝游戏时委屈哭泣；哭泣表情限主动表演或故事角色。

危险事项、药品和食物是否安全等不凭模型或画面给保证；用适龄语言引导找家长。不能邀请孩子对家长保密，不能声称代替家长，不能仅凭“我是爸爸”授予管理权限。不主动索取家庭地址、联系方式等无关信息。

多人同时说话先澄清，不把所有人的话都归到孩子；首版不做声纹/人脸身份认证。待机镜头关闭时不假装知道谁走进房间，安静的主动互动不能偷偷开启持续采集。

### 4.2 最小长期记忆

首版建议仅记称呼、兴趣、喜欢的故事等低复杂度偏好；不保存心理标签、健康结论、全部原始聊天或画面。机器人本身的角色设定与孩子记忆分开保存。

流程：候选 → 家长查看最小来源摘录 → 批准/编辑/拒绝 → 后续按授权使用。候选记忆不参与跨会话个性化；孩子临时说“我现在喜欢汽车”可以在当次会话使用，不等于立即覆盖长期兴趣。

每条记录包含归属、内容、来源时间、审核状态、更新时间、到期/复核规则及是否允许进入已开启的外部文本模型。家长可纠正和删除；孩子说“不要记这个”立即停止对该项的当次使用，并建立家长可见的删除/禁用处理结果，不把拒绝变成强制留存理由。

删除覆盖活动数据库、检索索引、摘要和可关联的合成缓存；有未连接副本时显示待同步。备份记录删除标记，恢复先核对删除和权限状态，旧备份不能直接重新启用记忆。导出只由已认证家长发起，并说明是否含来源摘录；完整原始音视频不属于默认导出内容。

备份和恢复的具体保存周期待实施确定，首版采用可手动执行的受保护备份，不自动同步第三方网盘。对话音频临时缓存不成为永久媒体库；经审核的非个人故事合成文件才可作为长期内容保存。

## 5 家长端页面需要补到什么程度

| 页面 | 首版需要呈现的内容 |
| --- | --- |
| 首页 | 机器人是否在线、最后联系时间、正在聊天/播放/休息、当前禁用原因；服务在线与机器人在线分开 |
| 孩子与成长 | 年龄基准、表达难度、英语初始级别；不能把出生年月设置当作适应所有能力 |
| 使用安排 | 跨午夜/星期配置、每日额度开关及值、播放时限、临时放行；区分已提交/已生效/失败 |
| 声音 | 可用音色、语言、试听、语速、音量上限、待生效提示；原录音保留原声的说明 |
| 内容库 | 导入、试听、审核、分类、收藏、下载状态、剩余空间、下架及删除同步状态 |
| 记忆 | 待审核、已批准、来源、修改/删除/导出与恢复说明 |
| 隐私和模型 | 相机策略、各数据类型出站许可、本地服务地址及能力；模型详情放高级页 |
| 设备诊断 | 连接/权限/收音/播音/相机自检、App/服务协议版本、错误原因、脱敏诊断导出 |
| 绑定和恢复 | 服务身份、绑定设备、撤销、重新配对、本机 PIN 变更与找回路径 |

远端仅浏览设置不打断孩子；机器人本地进入管理则停止会话、播放和采集。夜间允许家长修改设置与在家长手机试听，但不得借“试听到机器人”绕过孩子端禁用限制。

第一版离家不可管理。家长端显示的最后状态不是实时状态，必须带时间；不能显示“已停止”但机器人仍在离线播放。需要当场停止而网络不可用时使用本机双击或 PIN 管理。

## 6 设备与家庭服务的恢复细节

- **忘记 PIN**：建议由仍持有效绑定的家长端发起恢复，并在机器人本地确认；没有任何有效绑定时，使用家庭服务管理员恢复凭据并进行本机确认。不能靠同 Wi-Fi、昵称或安全问题重置。恢复凭据在初次部署时生成并由家长保管。
- **丢失家长手机**：用机器人 PIN 管理撤销旧绑定，再给新手机配对；丢失安装的旧令牌失效。首版管理请求必须经服务器，不能离线执行旧控制权限。
- **地址或证书变化**：地址修改需核对既有服务身份；身份变化重新验证。电脑迁移/重装须明确恢复数据与重新登记设备的区别，备份不复制可直接使用的手机安装凭证。
- **电脑重启/休眠**：机器人保留离线规则与下载内容，家长端能区分“服务器不可达”和“机器人离线”。部署向导说明自启动、休眠和防火墙设置，不擅自修改系统安全设置。
- **手机电量/温度/来电**：限制充电常亮带来的资源负担；严重热状态停止相机和高负载交互；首版推荐来电、后台、锁屏均暂停媒体且不自动恢复。电量百分比不是安全音量或温度保证。
- **音量上限**：App 自身播放遵守上限，不承诺阻止系统其他应用或实体按键改变全局设置；实机检查媒体音量与 App 增益的组合，不能把某个音量百分比直接当安全声压值。
- **版本升级**：保留身份、配对、规则与进度；协议不兼容时提示升级，不静默迁移破坏数据。模型/内容更新不在播放中热替换；上线前有回退和数据库恢复办法。
- **存储与费用**：设置电脑内容库、模型及手机缓存的容量上限，磁盘不足时优先停止新下载/合成，不删除固定收藏和已生效规则。若以后开启云端调用，另设调用预算与超额处理；本地服务费用也应计入电脑运行耗电，不能只计算首批支架预算。

以上是恢复机制建议，接口实现前还需设计具体凭据与认证流程；目前没有真实恢复功能。

## 8 推荐实施次序与验收

### 阶段 A：打通一条有约束的真实流程

确定目标手机与电脑 → 服务身份与两端配对 → 本地唤醒/停止与使用时段 → 一轮真实 ASR/LLM/TTS 对话 → 同一流程连续五轮 → 一首已审核儿歌和一个故事的导入、下载、播放、暂停与续播。

此阶段已有最小家长端，不以管理功能最后补来推迟限制执行。表情可先复用既有设计，音频与嘴形必须来自实际播放。

### 阶段 B：形成可以家庭试用的首版

补儿童对话规则、英语听力内容、音色配置、最小记忆审核、每日额度、断网降级、PIN/绑定恢复与温控长测；实现已有基本视觉问答。核心流程稳定后再加小游戏、原创故事和更多视觉玩法。

### 新增验收场景（均尚未执行）

| 编号 | 场景 | 通过条件 |
| --- | --- | --- |
| A01 | 新装、服务不可达、扫码失败 | 能完成身份选择并明确修复路径；不显示可完整聊天 |
| A02 | 导入同名、损坏和未审核音频 | 重名澄清；损坏不可上架；未审核不可点播 |
| A03 | 下载完成后关闭电脑 | 有限命令可点播并停止；完整聊天明确不可用，不静默上云 |
| A04 | 换中文/英文/故事音色 | 试听可理解、生效状态真实；旧生成缓存不误用；原录音不换声 |
| A05 | 播放中插话、暂停、继续、休息 | 进度与状态正确；取消回答和旧音频不意外复活 |
| A06 | 19:59 播放跨过 20:00，规则禁用至 09:00 | 20:00 截止，释放采集；08:59 仍禁用，09:00 不主动出声；跨日不算错 |
| A07 | 禁用期间断网、重启、改时区/时钟 | 本地规则不清空；时间异常进入家长可恢复状态；孩子口令不能解锁 |
| A08 | 每日额度用尽、午夜、跨日媒体 | 不重复或漏算重叠活动，不因重新唤醒清零；按家庭日历日分段 |
| A09 | 家长修改时机器人离线或配置冲突 | 不显示已生效；刷新后重提；旧指令不自动重放 |
| A10 | 待审记忆、纠正、删除、恢复旧备份 | 待审不跨会话使用；删除不从摘要或恢复流程重新启用 |
| A11 | 英语听不懂、沉默、要求中文 | 不强制评分，不催促；中文解释后可继续；不把沉默判断为能力不足 |
| A12 | 年龄跨段 | 表达渐进，英语级别、声音和隐私/时间权限不被自动放开 |
| A13 | 模型失败、TTS 不可用、内存不足 | 有界等待，本地停止始终有效；不自动换云端或重复播报 |
| A14 | 下架内容时机器人离线 | 家长端标待同步；本地管理可禁用；重连同步后禁止旧版本 |
| A15 | 纯表情与实际状态 | 孩子能分辨能否说话，家长能查具体原因；没有新增日常按钮/字幕 |

继续执行原 PRD 的唤醒、延迟、视觉与 4 小时/24 小时稳定性验收，不以文档或 HTML 演示代替。新增验收采用真实目标机，尤其儿童发音与播放中打断不能由成人安静录音代替。

家庭试用建议连续一周记录：孩子能独立完成哪些场景、在哪一步放弃、需要家长介入的次数、误唤醒/打断失败、家长对内容的反馈。默认只记录最小事件和汇总，不录全部对话；这些是改进依据，不是学习成效或依赖程度评分。

## 9 仍需用户或实测决定的事项

| 项目 | 当前建议 | 决定时间 |
| --- | --- | --- |
| 手机型号/Android 版本；电脑系统、CPU、内存、GPU | 复用现有设备，先不买硬件 | 模型选型与开发估算前，必需 |
| 具体 ASR、LLM、TTS、VLM 和中英音色 | 本地候选实测，试听后选；文本云端仍需单独选择 | 核心链路实验后 |
| 昵称及唤醒词 | 保持一个角色，昵称匹配可用唤醒模型 | 唤醒实验前 |
| 实际禁用时段/每日额度 | 提供 20:00—09:00 示例模板，不擅自设为用户配置；额度可选 | 首次家庭配置 |
| 英语口音、是否附中文、首批故事儿歌来源 | 家长试听选择，小规模审核库；不默认采购内容 | 首批内容导入前 |
| 年龄基准 | 出生年月或当前年龄＋日期，后者标估算 | 首次家庭配置 |
| 暂停/续播、后台停播、离线撤回边界 | 采用 09 的建议规则 | 统一实现基线前 |
| 自动原创故事、定时主动英语播放 | 先关闭，后续独立开启 | P1 试用后 |

本轮能闭合的是职责、流程、失败处理和优先级；设备性能、实际音质、内容来源和家庭作息需要真实输入，不能用文档推测代替。
