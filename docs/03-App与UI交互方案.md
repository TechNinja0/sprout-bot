# 纯表情语音机器人 UI 与动效方案

版本 1.1　修订日期 2026 年 9 月 22 日　状态 设计修订版

本版取消上一版的工具型首页。日常全屏只有一个有眼神、嘴形和表情变化的机器人脸，用户通过语音完成叫醒、提问、看东西、唱歌和讲故事。对话结束，脸慢慢回到待机，不出现“开始说话”按钮。

## 1 视觉方向

采用深墨色背景和柔亮的浅青眼睛，眼睛由外轮廓、深色瞳孔、小高光和可变化的眼睑组成。加入克制的嘴形、眉形与脸颊，解决旧版只有两个圆点、情绪辨识度不足的问题。轮廓保持圆润，动画连续，表情之间能看出同一个角色。

正常画面无标题、状态文字、字幕、相机预览、菜单、卡片或可见按钮。表情图鉴中的名称标在各画面外，属于设计说明，不进入机器人屏幕。动态预览默认也是纯脸；设计评审工具需通过键盘 D 或隐藏长按入口打开，不代表产品会显示调试面板。

首次设置、系统权限与 PIN 管理页单独存在。系统隐私指示由 Android 管理，不纳入可隐藏的 UI 元素。故障用语音说明并回到可辨识表情，不把错误文本放到脸上。

## 2 状态与心情图鉴

| 表现 | 眼睛和眉形 | 嘴形和动作 |
| --- | --- | --- |
| 待机 | 半睁，视线轻微漂移，缓慢眨眼 | 小弧形嘴，平缓呼吸 |
| 听你说 | 双眼睁开，瞳孔聚焦，轻微歪头 | 嘴收拢，停止播音动作 |
| 思考 | 视线上移，一侧眉形略抬 | 嘴轻偏，缓慢回正 |
| 看东西 | 眼睛略收窄，视线集中在前方 | 小圆嘴，轻微前倾后保持 |
| 说话 | 自然注视与眨眼 | 嘴开度随真实音频幅度变化 |
| 唱歌 | 弯弯的眼睛或随节奏张开 | 张合嘴，轻微左右律动，不显示歌词 |
| 讲故事 | 眉形和视线随句子变化 | 语句节奏嘴形，小幅叙述动作 |
| 开心 | 瞳孔变亮，眼睛柔和抬起 | 上扬微笑，少量脸颊色 |
| 大笑 | 眼睛眯成弧线 | 大开口和轻微弹动，短时回落 |
| 委屈 | 内侧眉毛抬起，眼睑下压 | 下弯小嘴，轻微低头 |
| 大哭 | 眼睛紧闭，泪滴从眼下落下 | 夸张哭嘴，短时抽动，可随时打断 |
| 休息 | 合眼，完全平稳 | 嘴放松，无持续媒体动作 |

工作状态决定真实任务；心情作为表演层叠加。例如“讲故事 + 开心”是叙述动作加微笑，不能为了播一段大笑动画暂停取消命令。大哭和委屈是用户要求的表达能力，采用故事角色或主动表演触发，不表达机器人真实受伤或要求用户安慰。

## 3 唤醒和连续对话的完整动效

待机时脸保持低频活动。听到昵称，眼睛在约 220ms 内睁开、眉形抬起，嘴给一个短回应；相机启动同时进行。回应结束立即收嘴，转为注视和轻歪头，表达可以继续说。首句可以紧跟唤醒词，不要求用户等按钮出现。

用户讲完后转入思考，眼神短暂上移；模型开始输出但声音还没播出时，嘴不能提前持续说话。声音真正开始才张合，播放结束后回到聆听脸，保留已确认的 30 秒继续提问时间；不用回到闭眼或要求重复叫名。

快到无输入超时时只做轻微回落，不倒计时、不催促。超时后播放一次结束提示音，合眼一下，回到可叫醒的待机。用户说“休息吧”同样退出并关闭摄像头。完全静音则由家长设置区分，不可仍声称能叫醒。

## 4 视觉问答动效

“这是什么”先切观察眼神，再看当前新帧；期间不把相机画面显示出来。识别到物体后回到说话脸，口头说明“我看到的是一个杯子”。多物体时用疑问眉形并口头问清楚，模糊时请用户把物品放远或调整光线。

相机随语音会话唤醒，不需要再喊一次“打开摄像头”。名字唤醒与提问之间保留最新帧，避免每次重新启动带来的等待。更换物体时重新取图；问“它有什么用”可复用刚才对象的上下文。视觉返回太慢时仍允许叫昵称中断，不冻结脸或阻塞停止。

## 5 唱歌和讲故事

唱歌以播放已授权歌曲为第一版路径，脸跟随音乐幅度和节拍变化；没有真实音频时，只能称表情动画演示。讲故事以真实语音句子驱动嘴形，可通过故事标签切换开心、委屈、大笑和大哭，叙述结束平滑回到聆听。

“停一下”中止播放并继续会话；“休息吧”结束会话。播报期间支持再次叫昵称打断，自然不叫名插话在双讲验证后开放。长媒体不无限期开启相机，30 秒无用户输入即关闭视觉采集，后续叫昵称再开。

## 6 隐藏管理和兜底操作

家长在右上角空白处长按 2 秒后进入 PIN 页面，PIN 正确后才能查看设置。此手势在首次设置讲解，脸上没有“家长”标签。管理页包含真实麦克风和相机状态、唤醒灵敏度、时限、声音、内容库、视觉服务、记忆、诊断和退出。

双击脸部立即停止当前动作与语音；它是无文字的紧急兜底，不是主入口。声音完全不可用等故障时，面部保持休息状态，家长可以用约定手势检修。不存在因为脸上没有按钮就无法退出的情况。

## 7 动画技术参数

角色局部坐标采用 1000×600，按可用屏幕等比缩放；横竖屏都保留完整脸，额外区域保持同背景，不拉伸眼睛。正式 Android 使用 dp 与系统安全区域适配，不把设计像素直接当物理像素。

表情切换初值 180 至 320ms，眨眼约 140ms；非表演状态眨眼间隔约 3 至 7 秒。说话嘴形读取真实音频包络，唱歌的左右摆动初值不超过 4 度。委屈和哭泣的强度可配置，短表演结束自动回到当前业务状态。

降低动态效果时去除弹跳和头部摇摆，保留眼睑、嘴形、视线和短提示音。待机降低刷新频率和亮度，停止持续高负载渲染；不承诺某一种动画策略能完全避免 OLED 烧屏。

## 8 设计预览的使用方法

06-动态表情预览.html 可离线打开，无远端资源、无摄像头或麦克风权限请求、无真实 AI。默认自动轮播 12 种表情，屏幕不显示控制内容。按 D 打开评审面板，选择表情、暂停轮播或演示“唤醒 → 多轮对话 → 观察 → 回答 → 休息”的流程；按 Escape 关闭面板，F 请求全屏。
