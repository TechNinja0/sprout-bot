# 家庭小伙伴：家长与孩子使用手册

适用版本：`0.1.0`（首个正式版，家庭局域网内部分发）。更新日期：2026-09-23。

这份手册教你完成手机连接、设置使用时间、添加故事和图书，再带孩子学会叫醒、提问、听书和停止。按钮名称按当前 App 源码核对；不同手机的系统安装、文件选择和权限页面可能不同。当前版本仍有儿童声学、实体图书和稳定性项目待验收，第一次请由家长陪同试用。

## 怎么阅读

- **电脑和手机都还没有设置好**：从第 1 节开始；电脑安装交给负责搭建的人，命令在附录。
- **已经能看到机器人脸**：先完成第 3 节检查，再跟孩子练习第 4 节。
- **想添加故事、儿歌和图书**：看第 6 节。
- **机器人没有反应**：直接查第 10 节。
- **想给孩子留一张提示卡**：使用第 11 节，可单独复制或打印。

遇到问题时，家长端“维护”可刷新并保存脱敏诊断。机器人 PIN 管理页还可显式启动最多 30 秒的本机自检：短时录音、家庭语音识别、新画面和半秒提示音；结果不等于儿童实际使用效果，识别文字离开页面即清除。自检同样服从静音和使用时间。详细说明见[诊断与记忆撤回](engineering/诊断与记忆撤回实现说明.md)。

孩子说“不要记这个”，会撤回刚刚明确要求保存的偏好；指代不清时先停用既有偏好，由家长在“记忆”逐条核对。只有明确说“删除全部记忆”才删除全部，不会把单项拒绝当作清空所有兴趣。

## 1. 家里需要准备什么

| 设备 | 用来做什么 | 使用时的要求 |
| --- | --- | --- |
| 家庭电脑 | 处理语音、回答问题、识别图书，保存家庭资源库 | 已安装服务和模型；在线互动时保持开机，服务运行且电脑不休眠 |
| 机器人手机 | 显示小伙伴的脸、听孩子说话、播放声音 | Android 10 或以上；安装 App，选择“机器人身份”，保持 App 在前台 |
| 家长手机 | 设置时间、管理内容和配对 | 当前家长端也是 Android App，安装同一个 APK，选择“家长身份” |
| 家庭网络 | 让手机与电脑互相连接 | 初次使用让三台设备连接同一家庭局域网；不需要购买域名 |

日常使用建议把两种身份放在两台手机上。同一台手机可以切换身份，但进入家长页面后，不能同时保持机器人脸和正常儿童互动。

请负责搭建的人先完成：安装模型、启动服务、安装 APK，并提供当前家庭电脑生成的**连接文件**。不要拿旧测试配对文件直接用于家庭正式配置。当前工程的 APK 路径为 `android-app/app/build/outputs/apk/debug/app-debug.apk`，属于调试包；安装步骤和电脑准备见附录。

手机摆稳，避免遮挡麦克风、扬声器和摄像头。先用舒适的小音量试播。

## 2. 第一次连接：先机器人，再家长

### 2.1 连接机器人手机

1. 打开 App，在“连接家庭机器人”页面选择 **“机器人身份”**。
2. 请负责搭建的人此时生成连接文件。文件通常叫 `connection.json`，**只有两分钟有效**，准备好手机后再生成。
3. 把文件通过你们自己的可信方式传到这台手机，点 **“导入连接文件”**，在系统文件选择器中选中它。也可以把文件内容填入“连接材料 JSON”。
4. 设置 **6—12 位数字管理 PIN**，由家长保管。
5. 点 **“验证并连接”**。连接成功后进入机器人界面。
6. 按系统提示允许麦克风权限。需要看物体或看封面读书时，也要允许相机权限。

**JSON 从哪里获取？** 它不是需要自己填写的配置模板，而是家庭电脑的服务命令生成的 `runtime/connection.json`，包含服务地址、证书指纹和短期邀请码。具体生成命令见本文附录 C；未安装电脑服务时先按附录 A 完成搭建。

“扫描二维码”需要相机权限，首次点击会请求授权；打开后对准二维码，会自动识别，无需拍照保存。拒绝授权后仍可导入文件或粘贴 JSON。电脑初始化命令提供 JSON 文件；机器人管理页生成的家长配对材料会直接显示二维码。普通网址二维码不能替代连接材料。

连接材料过期时，请重新生成并导入。不要反复提交旧文件，也不要把连接材料发到公开群或问题反馈截图中。

如果漏掉权限设置：在机器人脸部**右上角长按 2 秒**，输入 PIN，点“进入”，再点 **“检查麦克风与相机权限”**。系统不再弹窗时，到手机系统设置中的该 App 权限页修改。

### 2.2 绑定家长手机

1. 在机器人脸部**右上角长按 2 秒**，输入 PIN，进入“机器人管理”。
2. 点 **“生成家长配对材料”**，App 直接显示二维码和剩余有效时间；二维码两分钟有效，过期点 **“重新生成”**。
3. 家长手机打开同一个 App，选择 **“家长身份”**。
4. 点 **“扫描二维码”**，允许相机权限，对准机器人手机上的二维码；识别成功后自动返回，点 **“验证并连接”**。
5. 回到机器人手机，点 **“返回管理页确认配对”**，会刷新待确认请求；未看到时点 **“刷新待确认配对与设备”**。确认请求确实来自自己的家长手机后，点 **“亲自确认”**。
6. 回到家长手机，点 **“检查机器人确认结果”**，完成绑定。
7. 机器人手机点 **“返回小伙伴”**，恢复机器人脸。家长手机可留在管理页面。

不方便扫码时，仍可在机器人管理页点 **“保存配对文件（备用）”**，传到家长手机后选择“导入连接文件”。

**家长手机不能直接使用电脑给机器人生成的连接文件。** 两个文件用途不同；家长配对还需要机器人本机确认。超时就从生成配对材料重新开始。

### 2.3 以后还要重新连接吗

正常关闭再打开 App，会记住已保存的身份，不需要每天配对。换电脑、清除 App 数据、凭据被撤销或服务身份变化时，才需要按相应流程重新连接。遇到证书不匹配，请让负责搭建的人核对，不能靠忽略错误继续连接。

## 3. 第一次交给孩子前，家长先检查

家长端顶部的页面标签可以**左右滑动**。看不到“声音”“维护”等入口时，横向滑动标签栏。

| 检查位置 | 怎么设置或确认 |
| --- | --- |
| 首页 | 查看机器人是否在线，以及语音识别、朗读、对话能力是否可用 |
| 成长 | 默认昵称“小伙伴”；填写孩子的基准年龄、对应日期及英语阶段。英语零基础就选择“零基础” |
| 使用安排 | 初始推荐为每天 20:00—次日 09:00 禁用、连续媒体 30 分钟、每日额度 0（不设额度）；核对这是否适合本家庭 |
| 声音 | 选择音色和语气，点“试听回答语气”或“试听故事语气”；同时检查App音量、手机媒体音量和声音输出位置 |
| 隐私 | 检查“麦克风静音”是否关闭；看图时开启“允许会话内看图”；按需决定是否开启“允许原创故事” |
| 英语计划 | 默认不主动播放；第一次可先保持计划关闭，手动验证播放 |

这些是初始推荐，**已经测试或使用过的设备可能不是这些值**。尤其是长时间测试后的手机，请重新检查禁用时段、音量和自动计划。

每次修改配置后，点 **“保存并等待机器人应用”**，看到 **“机器人已应用配置”** 才表示生效。“已发送”还不等于机器人已经应用。超时或冲突时先刷新，核对当前设置再重试。

第一次先做四件事：叫醒小伙伴、问一个简单问题、播放一条已发布内容、双击脸部暂停。都能完成后，再带孩子体验。

## 4. 第一次教孩子：家长照着做一遍

先把机器人手机停在脸部界面，确认现在属于允许使用的时间。

### 第一步：叫它的名字

家长示范说：**“小伙伴。”**

等它回应，再说：**“你好呀。”**

也可以轻点脸部叫醒。允许使用时，轻抚额头或揉脸也能叫醒并有对应回应；双击仍优先暂停，不会同时触发单击叫醒。

然后让孩子试一次。可以告诉孩子：“先叫名字，等它答应，再说一句话。”如果家长改过昵称，就使用新昵称。先把唤醒和问题分开练习，不必一次说很长。

### 第二步：一人一句地聊天

可以问：“小猫为什么会喵喵叫？”或“苹果用英语怎么说？”

等它说完再提下一个问题。回答结束后，约 **30 秒内可以直接继续问**；超过等待时间，重新叫名字。每次发言尽量简短，单次最多接收 30 秒。

一次连续问答最多约 **10 分钟**，到时会结束这轮互动；它也会遵守家长设置的禁用时段和额度。

### 第三步：听一个已经放进书架的故事

家长先按第 6 节添加并发布故事。然后叫醒小伙伴，说：**“播放小兔回家。”**（把“小兔回家”换成自家已发布的故事名称。）

也可以说“听故事”或“听英文歌”，前提是资源库中已经有适龄、对应语言和英语阶段的已发布内容。它不会因为这句话自动去网上找歌或下载图书。

### 第四步：学会随时停下

播放时说：**“停止。”** 如果没听见，直接**双击脸部**，也就是快速点两下。

暂停的书或音频可以说 **“继续”**。这不表示任意已经结束的聊天回答都能续播。

今天不玩了，说 **“休息吧”**。可以告诉孩子：“想停随时能停，不用等它讲完。”

### 第五步：想看图、读书或玩游戏时

| 孩子想做什么 | 可以这样说 | 家长先准备什么 |
| --- | --- | --- |
| 看一个物体 | “这是什么？” | 开启会话内看图和系统相机权限；把物体放在摄像头前 |
| 读手里的书 | “读这本书。” | 提前录入并发布正文，把清晰封面朝向摄像头 |
| 翻到下一页 | “下一页。” | 正在播放或暂停的是有页面正文的图书 |
| 回到上一页 | “上一页。” | 同上；普通歌曲不按图书页码翻页 |
| 玩一个短游戏 | “玩猜谜游戏。”或“玩数数游戏。” | 电脑服务在线；游戏最多三题、两分钟 |
| 不让它继续看 | “不要拍了。” | 关闭本轮相机；日后长期不允许看图可由家长在“隐私”里关闭 |

看封面时，先叫醒小伙伴，再展示封面并提出读书请求。**只拍封面不会得到整本正文**。找不到书就由家长录入；同名版本不明确时，由家长在资源库中选对版本并点“机器人播放”。

孩子翻动纸质书不会让朗读自动翻页，需要说“下一页”。开始朗读后不必一直举着封面。

看物体时，“这个怎么用”会重新看眼前画面，“它怎么用”沿用刚才已看清的对象。没看清时先调整光线和位置；有两个候选时可说名称、颜色或“第一个/第二个”。普通“这个故事好听”和“不要记这个”不触发发送画面。当前模型的实物识别仍在验收，家长不要将用途回答当作已经确认实物安全。

## 5. 每天怎么开用、休息和结束

### 开始前

1. 确认家庭电脑已经开机，机器人服务和本地模型服务正在运行；如果有人已启动，不要再开一份。
2. 机器人手机连接家庭网络，打开 App，留在脸部界面。
3. 需要时在家长端点“刷新”，检查在线状态和使用安排。
4. 叫“小伙伴”，开始互动。

机器人手机需要前台运行。锁屏、切到其他 App 或进入管理页会中断正常互动；不要把它当成锁屏后也能随时唤醒的系统语音助手。

### 暂停与结束

- **临时暂停播放**：说“停止”或双击脸部；需要时说“继续”。
- **结束这轮互动**：说“休息吧”。
- **今天不再使用**：停止互动后退出机器人界面或锁屏；后台会停止播放并释放相机和录音。
- **家长想立即禁止使用**：在“使用安排”打开“立即停用”，再保存并确认应用。若网络不通，直接到机器人手机停止播放并退出 App。

电脑服务运行在终端时，关闭终端或停止进程会让在线功能不可用。具体启动、停止方法见附录。

### 这些表情大致是什么意思

| 表现 | 通常代表什么 | 怎么处理 |
| --- | --- | --- |
| 青色睁眼、安静待着 | 等待唤醒 | 叫昵称或轻点脸部叫醒；回应结束、嘴巴收起后继续说话 |
| 暗灰色闭眼 | 麦克风静音 | 家长检查“隐私”设置 |
| 淡紫色闭眼 | 使用时间或额度限制 | 家长检查“使用安排” |
| 琥珀色眼睛 | 连接或录音权限等故障 | 进入机器人管理查看具体原因 |

表情也会随对话变化，不能只凭颜色判断全部原因；具体状态以管理页为准。

## 6. 家长怎样添加故事、儿歌和图书

### 6.1 先做一个最简单的文字故事

第一次建议先用自己写的几句话练完整流程，不必一上来扫描整本书。

1. 家长端进入 **“资源库”**，选择 **“故事”**。
2. 在“新资源名称”填写“小兔回家”，点 **“创建草稿”**。
3. 填写语言、适龄范围和来源等信息。“来源”可以写“家长原创”；需要孩子口头点播时，可以加一个好叫的别名。
4. 点 **“手工添加文字页”**，在“校对原文”中填入自己的故事。例如：

   > 小兔出门找朋友。天快黑了，它和朋友挥挥手，回家吃晚饭。兔妈妈说：欢迎回家。

5. 检查文字，打开 **“已逐字校对本页”**。若这就是全部内容，打开 **“已录入完整内容”**；若只是节选，填写“节选范围”。
6. 选好本资源朗读声音和语速，点 **“保存草稿”**，再点 **“试听当前页”**。
7. 试听满意后，打开 **“已试听并确认可发布”**，点 **“发布给机器人”**。
8. 发布成功后点 **“机器人播放”**，确认机器人手机能正常播放，再让孩子试说“播放小兔回家”。

**草稿保存后不会自动对孩子开放，必须发布。** 修改正文、页序、声音或完整范围后，要先保存、重新试听，再勾选试听确认。否则可能提示“请先完成试听确认”。

“试听当前页”最多读取当前页前 600 个字符，并不代表已听完整本。较长内容发布后，请先由家长试播，重点检查后半段、分页和结尾，再交给孩子。

### 6.2 添加一本纸质图书

1. 在资源库选择 **“图书”**，输入书名并创建草稿。
2. 填写书名、别名、版本、作者、语言、适龄范围和来源；ISBN 有就填写。
3. 点 **“导入封面”**，选择手机里准备好的清晰封面图片。
4. 点 **“导入书页 / PDF / 文本”**，选择内页图片、PDF、TXT 或 Markdown。纸质书先用手机拍照保存，再导入；封面不能替代内页。
5. 等待处理，点 **“刷新导入结果”**，查看生成的页数和导入任务状态。
6. 用“上一页”“下一页”逐页检查。可点 **“查看本页源图”**，对照“校对原文”修正错字、漏字和标点，检查页码、章节和页序。
7. 顺序不对可以用“向前移动”；重复页可删除；漏页可继续导入或手工添加。不朗读的页面可标记“本页不朗读”，但仍需检查并确认校对。
8. 每页打开 **“已逐字校对本页”**。确认完整内容或填写准确的节选范围。
9. 保存草稿、逐页试听，确认后勾选“已试听并确认可发布”，再点“发布给机器人”。
10. 先点“机器人播放”检查正文，再和孩子练一次展示封面、请求读书、翻页和停止。

单个导入文件最多 **32MB**，一本图书最多 **300 页**。大文件请先拆分。导入失败时检查任务提示，修正素材后再导入，或使用“重试导入”；正在处理的任务可以“取消导入”。

“发音映射 JSON”是高级字段，不熟悉时保持默认。遇到多音字问题，先确认正文正确，再请负责维护的人协助调整读音。

### 6.3 添加儿歌或已有录音

选择“儿歌”创建草稿，填写名称、语言、适龄和来源，点 **“导入音频”**，选择已有的 MP3、M4A 或受支持的 WAV 文件。保存草稿后点 **“试听已上传原音频”**，检查内容和范围，再勾选试听确认并发布。

儿歌必须有实际音频，**只输入歌词不会生成演唱**。更改合成声音也不会把上传的真人录音换成另一种声音。

只有文字、希望普通朗读的内容，请选“故事”或“英语短句”。

### 6.4 修正、下架和删除

| 想做什么 | 操作 |
| --- | --- |
| 修正错字或补页 | 打开资源，修改草稿，重新校对、保存、试听、发布；需要离线使用时重新下载新版 |
| 暂时不让孩子使用 | 打开资源，点“下架”，保留内容以便以后整理 |
| 彻底删除 | 点“删除资源”，阅读确认框后再决定；会删除服务器上的相关内容 |
| 只腾出手机空间 | 点“清理离线副本”，保留电脑资源库中的内容 |

如果旧内容需要立即停止使用，先下架并在机器人本机停止。**离线手机收不到立即撤回**，必须重新联网完成清理；家长手机上点了下架或删除，不代表离线副本已经消失。

## 7. 使用时间、英语计划和声音

### 7.1 设置作息

在“使用安排”中设置：

- **每日使用分钟**：`0` 表示不设每日额度，不是禁止使用。额度统计实际互动和播放，空闲等待不计入。
- **连续媒体播放上限分钟**：限制一次连续听故事或歌曲的时间。
- **禁用时段**：填写开始、结束时间并选择星期。`1—7` 对应周一到周日；例如开始 `20:00`、结束 `09:00` 表示跨过午夜，到次日上午 9 点结束。
- **立即停用**：家长手动禁止使用；恢复时需关闭并保存。
- **家庭时区**：中国大陆通常填 `Asia/Shanghai`。

每次修改都要点“保存并等待机器人应用”。确有需要时可点 **“临时放行15分钟”**，然后保存；临时放行不会取消“立即停用”，也不改变原来的长期安排。

到休息时间会停止，解禁后不会自己接着播放旧内容，需要重新主动开始。

### 7.2 整理清单，按需启用英语计划

1. 先发布几条合适的英语内容。
2. 进入 **“清单”**，填写名称，勾选内容，点 **“保存播放清单”**。
3. 可先点 **“播放这个清单”**，确认机器人能播放。
4. 想定时播放时，进入 **“英语计划”**，点 **“添加未启用计划”**。
5. 选择清单、星期、开始时间和本次最多分钟（1—30），再打开启用开关。
6. 点“保存并等待机器人应用”，确认成功。

计划只有在机器人**前台待机、服务在线、时段和额度允许**时才会开始。聊天或播放时不插播；错过时间、断网重连或重启后不补播。定时计划也不能越过禁用时段。

### 7.3 调整声音与英语难度

在“声音”里选择中文、英语及故事声音，设置回答语气、故事语气、音量和语速偏好。修改“试听文字”，分别点“试听回答语气”和“试听故事语气”；试听使用尚未保存的设置，满意后仍需点“保存并等待机器人应用”。当前Qwen模型的语速是偏好，实际节奏由模型决定。

“叫醒时的回应”可选“语音回应”“短提示音”或“仅表情”，点“试听唤醒反馈”检查效果；“轻抚和揉脸时使用顽皮回应”控制相应趣味反馈。正在连续对话时，触摸只做短暂无声表情，不插播话语。选择仅表情或把音量调为零后，不会偷偷提高手机音量。固定唤醒短句是App自带声音，修改对话音色不会即时改变它们。

单本资源有自己的朗读声音。只改全局声音不会改已发布图书；修改图书声音需要保存草稿、重新试听并发布。普通改版允许当前旧版读完，下次在线点播新版时会提示从头读；不把旧位置套到新版。已完整下载的旧版离线仍保持原声，需要重新点“下载到机器人”，等完整下载成功后才换成新版。下载中断不会把未完成的新文件当成可播放资源；需要立即停止旧内容时用“下架”。

在“成长”里由家长选择英语阶段。孩子年龄增长不会自动提高英语难度，也不会自动放开使用时间或相机权限。

## 8. 没有网络或电脑关机时怎么办

没有完整离线副本时，已发布也不等于离线可播。请在网络正常时提前准备：

1. 家长端打开一条已发布资源，点 **“下载到机器人”**。
2. 到 **“维护” → “查看机器人离线资源状态”** 检查结果。“已发送”只是请求发出，不是下载完成。
3. 当前页面可能显示英文状态：`downloading` 是下载中，`downloaded` 是已下载，`failed` 是失败，`pending_removal` 是等待撤回清理。
4. 在机器人本机进入管理页，确认资源出现在 **“完整离线资源”**，点 **“播放：资源名”** 试播。它会返回机器人界面播放。

断网后，家长可以用机器人本机的“完整离线资源”入口选内容。部分受支持的中文书名或别名也可用“读＋名称”点播，但不保证每个名称都能识别；本机列表是更稳妥的入口。

离线时不提供完整自由对话、看物体或封面识书；家长手机也无法通过已经关机的家庭电脑远程管理。时间和额度限制仍然生效。

## 9. 隐私、家长手机和备份

### 相机和麦克风

正常待机时，手机在本地听唤醒昵称；进入会话后，发言才交给家庭电脑识别。允许看图时会话内可开启相机，问物体或封面时使用画面；不想看图可以关闭“允许会话内看图”，或在本轮说“不要拍了”。

本项目默认使用家庭电脑上的模型，不启用云端音视频或对话通道。会话相机画面不保存；家长主动导入的封面、书页和录音会保存在资源库。手机系统出现相机或麦克风使用指示时属于正常权限提示。

“记忆”页由家长审核明确偏好，可以批准、拒绝、删除并设置有效天数。“摘要”查看使用时长和部分失败统计，不是孩子学习成绩，也不是逐句聊天记录。

### 更换 PIN 或撤销家长手机

在机器人管理页填写“新的管理 PIN”，点 **“修改 PIN”**。连续输错 5 次需要等待 5 分钟。

家长手机遗失或不再使用时，在机器人管理页点“刷新待确认配对与设备”，找到对应家长设备并撤销。家长也可以在自己的“维护”页点“撤销本机家长凭据并退出”。只是退出页面不等于撤销权限。

忘记 PIN 时，请负责搭建的人按工程维护手册的恢复流程处理。不要自行清除 App 数据试运气；这会丢失手机身份和离线副本，需要重新登记。

### 备份家庭资源

在家长端 **“维护” → “导出资源库备份”**，选一个自己保管的位置保存 ZIP。建议大批量录入或重要修改后备份一次。

资源备份不包含设备登录凭据和生成音频，不能替代电脑整套服务的灾备。恢复需要电脑管理员恢复凭据，内容恢复为**待审核草稿**，要重新核对、发布和生成音频。手机恢复文件上限 32MB，更大的备份请交给负责搭建的人在电脑处理。

## 10. 常见问题：按顺序排查

| 遇到的问题 | 先做什么 | 还不行怎么办 |
| --- | --- | --- |
| 叫“小伙伴”没反应 | 确认脸部界面在前台、当前允许使用、未静音，麦克风权限已允许 | 进入机器人管理查看原因；可用“测试唤醒”区分会话能否启动，但这个按钮不代表语音唤醒已经验证成功 |
| 晚上突然不理人 | 检查是否进入禁用时段，默认推荐从 20:00 开始 | 家长按实际需要调整并保存；也检查每日额度和立即停用 |
| 能看到脸但不能回答 | 检查电脑是否休眠、两个服务是否运行、手机和电脑是否同网 | 查看首页能力状态或维护页模型状态，请负责搭建的人检查服务 |
| 连接文件无法使用 | 核对身份和文件用途，检查是否超过两分钟 | 重新生成对应材料；证书问题交给负责搭建的人核对 |
| 家长端一直等配对 | 在机器人本机刷新请求并“亲自确认” | 再到家长手机“检查机器人确认结果”；超时重新配对 |
| 配置点保存却没生效 | 等待“机器人已应用配置”，保持机器人在线 | 刷新后核对、重试；不要把“已发送”当成功 |
| 有嘴形但听不到声音 | 检查 App 音量、手机媒体音量和蓝牙声音输出 | 试听一条已知正常的内容，检查是否被电话或其他 App 暂停 |
| 图书找不到 | 确认已经发布，允许相机，封面文字清晰且版本正确 | 家长从资源库选中图书点“机器人播放”；缺书先录入 |
| 图书读错、漏字 | 对照源图检查“校对原文”和页序 | 修改后保存、重新试听和发布；不要只重复拍封面 |
| 发布提示未校对或未试听 | 每页确认校对，填写完整或节选范围 | 保存全部修改后重新试听，再勾选试听确认并发布 |
| 英语计划没有播放 | 检查计划启用、清单有效、时间和星期正确 | 确认当时在线且前台待机；错过时间不会补播 |
| 断网后不能听书 | 确认下载状态是 `downloaded` | 在机器人本机“完整离线资源”试播；未完成的资源需联网重下 |
| 下架后离线设备仍有书 | 在机器人本机停止使用 | 让设备联网完成撤回清理，再检查状态 |

反馈问题时，记录**发生时间、所在页面、刚才的操作、屏幕错误文字、是否联网**即可。截图避开 PIN、连接材料、恢复凭据和家庭私密内容。

## 11. 给孩子的小卡片

> **我和小伙伴这样玩**
>
> ① 先叫：“小伙伴！”等它答应，再说话。
>
> ② 一次说一句，等它讲完，我再讲。
>
> ③ 想听故事：“播放……”说出家里书架上的故事名。
>
> ④ 想读书：让它看看封面，说“读这本书”。书要先请爸爸妈妈放进书架。
>
> ⑤ 想翻页：“下一页”或“上一页”。
>
> ⑥ 想停：“停止！”没听见，就快速点两下它的脸。
>
> ⑦ 不玩了：“休息吧。”
>
> 它没听懂或说错了，可以请爸爸妈妈帮忙，不用一直重复。

家长可以第一次示范“叫醒—提问—听故事—停止”，再让孩子各做一遍。孩子不想继续时就结束，不需要完成全部功能。

## 附录：交给负责电脑搭建的人

本节供维护者操作。家长日常使用不需要理解命令，也不需要每天重新初始化或配对。

### A. 首次安装与交接

按 [工程维护手册](engineering/工程维护手册.md) 完成依赖、模型、Ollama 模型拉取与校验、服务初始化、APK 构建和安装。以下命令不能替代首次安装步骤。

把调试 APK 通过可信方式复制到 Android 手机上，点击安装文件，按系统提示允许本次安装来源并安装。已有安装需使用兼容签名升级；不要为了处理安装错误直接卸载有家庭数据的 App。当前没有 iPhone 家长端安装包。

交接时请确认电脑不休眠、手机能通过家庭 Wi-Fi 访问服务，并留下启动方法。USB 调试连接正常不代表家庭 Wi-Fi 已连通。请先从测试配置恢复为本家庭认可的时间、音量和权限，再让家长更换 PIN。

### B. 电脑重启后的日常启动

在项目根目录打开两个终端。依赖和模型须已安装好；已有服务在运行时不重复启动。

终端一，启动本地模型服务：

```sh
bash scripts/run_ollama.sh
```

终端二，启动家庭机器人服务：

```sh
ai-service/.venv/bin/robot-service --data runtime serve --bind 0.0.0.0
```

需要停止时，先在机器人手机停止互动，再在各服务终端按 `Ctrl+C`。这些是手动启动命令，不会自动配置开机自启；如果部署者已另行设置启动方式，以交接记录为准。

### C. 为首次机器人连接生成材料

在项目根目录执行。下面 `192.168.1.20` **只是示例，必须替换为手机可访问的家庭电脑局域网地址**。

首次服务初始化：

```sh
ai-service/.venv/bin/robot-service --data runtime init --host 192.168.1.20
```

服务已经初始化，只需重新生成过期材料时：

```sh
ai-service/.venv/bin/robot-service --data runtime invite --host 192.168.1.20
```

两者生成的文件都在 `runtime/connection.json`，两分钟有效。首次初始化后仍需启动服务；若安装、启动耗时导致材料过期，再运行 `invite`。**家长配对材料在机器人管理页生成，不能用这份文件替代。** 已登记机器人的恢复应使用维护手册中的 `recover` 流程，不用普通邀请代替。

## 图书录入与朗读补充（2026-09-23）

资源编辑新增“拍摄封面”“拍摄书页”“连续拍摄书页”“批量选择书页图片”，以及每页的旋转重识别、重拍替换和质量提示。可填写出版社；印刷页码不清楚时留空。电脑也可将 `runtime/inbox` 中的一本书目录显式导入为草稿。

孩子可在同名两候选中回答“第一本/第二本”，有同版进度时选择“继续/从头读”；可说“读第三页”或“读第二章第三页”。节选先读范围说明，再读原文。详细操作、失败处理及当前验证边界见[图书录入与阅读实现说明](engineering/图书录入与阅读实现说明.md)。

### 调整书页朗读顺序

批量导入后的列表初始顺序来自导入次序，不一定等于原书页码。印刷页码用于核对原书和“读第几页”定位，填写它不会自动重排书页。

在“逐页校对”中长按任一书页上下拖动，移到列表可视区域上下边缘可继续滚动；松手后按显示的“朗读顺序”排列。轻点书页仍进入正文校对，也可在单页“页序与删除”中向前或向后移动。取消拖动不会改变草稿。

调整后点击“保存草稿”；已发布的书还需重新发布，机器人获取新版本后按新顺序朗读。使用离线内容时需更新下载。若导入的是一整段原录音，拖动书页不会重排录音内容。
