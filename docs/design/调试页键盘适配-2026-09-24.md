# 调试页键盘适配

窗口显式使用 `adjustResize`，Compose 使用统一的边到边布局与系统栏/键盘 Insets。标题和页签固定，仅消息区域缩小并滚动。自动播放选项移至输入栏上方，移除输入栏底部多余内边距，切换语音输入时收起键盘。

## 验证

设备：当前连接的三星 SM-F9660，Android 17。华为未连接，本次未在华为复测。测试直接渲染调试页并进行本地输入，不向家庭服务发送测试消息；测试后逐字节恢复原身份及主题配置。

实际执行（构建使用 JDK 17）：

```sh
android-app/gradlew -p android-app :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug
adb -s R3CY20KH0MX shell am instrument -w -e class org.familyrobot.app.DebugKeyboardLayoutTest org.familyrobot.app.test/androidx.test.runner.AndroidJUnitRunner
git diff --check
```

结果：构建成功；Lint 0 错误、17 警告；真机布局用例通过（8.877 秒）；diff 检查通过。新版 APK 已安装并启动。

深色/浅色、单行/四行输入共四种状态均验证：标题上沿保持 152 px；键盘上沿和输入框下沿均为 1548 px，间距 **0 px**。键盘收起后标题仍保持原位。截图与测量结果见 `ui-audit/artifacts/debug-keyboard-20260924/files/debug-keyboard/`。
