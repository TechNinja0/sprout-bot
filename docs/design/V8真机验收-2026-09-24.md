# V8 华为真机验收

设备：华为 OXF-AN10，Android 12，USB ADB 5038。本次验收使用真实 Android App、独立 HTTPS 家庭服务、已安装的本地对话/TTS/ASR/OCR 模型及原创测试资料。原家庭服务未停止、数据库未迁移；验收前备份原 APK 和加密手机偏好。

## 本轮修复

1. 独立工作目录缺少被 Git 忽略的 KWS/VAD 资源，导致旧 V8 测试包可构建但不能在全新安装时完整初始化语音。补入本机已安装模型，并增加 `:app:verifySpeechAssets` 作为 `preBuild` 前置检查；APK 内核实存在 6 个模型/词表条目。临时移走 VAD 后构建按预期失败，随后恢复资源。
2. 补齐 Material 3 的 surfaceContainer 和 secondaryContainer 调色，修复浅色卡片与底部导航残留默认紫色；状态栏、导航栏随主题切换。
3. 管理页添加 IME 内边距，键盘弹出时可以滚动到保存/发送控件。用例同时修正同名“昵称快捷按钮”和输入框的选择歧义。
4. 状态请求设置 5 秒上限，避免沿用音频请求的长超时，让页面长时间保留过期的绿色连接提示；服务无响应与恢复通过独立服务进程暂停/恢复验证。
5. 唤醒词更新沿用“没有活跃会话、没有正在播放”的条件。媒体仅保留暂停进度时不再永久阻止换词表，停止/继续等控制词保持不变。
6. 修复家长端“使用摘要”返回时误跳首页，返回到进入它的设置页。
7. 原有导航、设备冒烟、本机自检和图书导入仪器用例更新到新二级页结构；没有删除原来的功能断言。
