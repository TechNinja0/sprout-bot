# 图书校对与试听发布

## 用户流程

采用“逐页校对可试听，全部确认收录范围后发布”；试听是可选检查。不要求把整本一次校对完，也不强制每页都听一遍。

1. 在书页列表查看已校对进度，点击书页编辑正文、页码、章节和发音纠正。
2. 可随时完整试听本页，检查读音；不朗读页无需试听。使用已有原录音时无法按正文页定位，改在最终页试听原录音。
3. 点击“保存并确认本页”后进入下一张待校对页；全部确认后进入“试听与发布”。“保存，稍后校对”只保存，不代替确认。
4. 最终页设置完整/节选范围、声音、情感、语速、补充语气和音质；选择一页完整试听，也可换页抽查。原录音保留原声，不提供不生效的换声设置。
5. 完成校对并确认收录范围即可发布固定版本；试听及声音确认均可跳过。发布成功显示短暂 Toast，不在页面保留成功横幅，也不会自动点播。

## 相对 V8 交互稿的还原与补充

V8 的 `gBookList()`、`gBookPage()`、`gPublish()` 已有书页列表、源稿对照折叠、重新识别折叠、保存并确认、完整/节选范围和声音配置。本次恢复这些层级，并补充逐页试听、确认后继续下一张待校对页、试听页选择与固定底部操作。

- 校对列表保留补页入口，单页内不再堆放整本的补页/发布按钮。
- 源稿对照、发音纠正、重新识别与替换、页序与删除分区折叠。
- 无源图时显示原因，不展示一排禁用的源图/识别按钮。
- 正文、跳过朗读、页码、章节或发音修改会撤销本页校对；不要求对未变更的其他页重复校对。
- 页序、声音、范围等修改撤销旧试听记录；不强制重新试听，已试听标记只绑定当前草稿。
- 试听按 550 个 Unicode 字符分段顺序播放，满足服务单段 600 字限制，不截断长页；使用与正式朗读相同的长词优先发音替换顺序。
- 试听进度/完成/失败提示放在试听按钮旁；支持停止、重播，离开页面或应用后台时停止。
- 空白页必须补齐正文或明确“不朗读”，前端确认和服务端发布都校验。
- 声音选项读取服务能力目录；引擎不支持的设置说明原因，不提供虚假选项。
