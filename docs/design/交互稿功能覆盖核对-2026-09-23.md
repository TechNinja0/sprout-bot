# 交互稿功能覆盖核对

核对日期：2026-09-23。对象：V5 交互稿、当前工作区源码、需求追踪及 OpenSpec 第 8—11 节。另一个任务“评审机器人产品文档”仍在运行；任务工具未返回最近轮次正文，因此以本地源码、任务清单及实现说明为证据。本文件是当前快照，不表示后续改动已被覆盖，也不修改其他任务的验收结论。

## 结论

V5 已覆盖主要导航、连接、配对、调试会话、家长播放卡片和图书核心录入流程，但不是完整功能设计。多项原有能力在新交互稿中遗漏，不能因开发任务已勾选就认为交互稿也已覆盖。V6 本轮只新增唤醒设置的双端入口及状态设计，其余缺口按下表保留。

## 交互稿已有，但不能说已在 App 实现

- 家长首页的资源名称、实时进度、可靠播放确认：已有 control API 基础；当前心跳没有完整媒体详情，控制 ACK 也不能直接证明音频真正开始。此前 3–5 人日估算只针对这部分。
- 调试聊天界面及可回放的历史会话、长期逐句陪伴记录：是新增设计。现有使用摘要、短期模型上下文、临时本机自检识别文字不等于历史对话产品。
- 标准/高品质两档：是 V5 新增的设计假设，现有 Voice schema 和 TTS 能力目录没有质量档位。不能把两种语音引擎直接当作面向用户的音质档位。
- 机器人身份下直接改唤醒设置：V6 新增入口设计。当前 config 写接口要求家长身份，PIN 管理页也没有改名操作。实现时需要本机 PIN 验证后的受限授权及服务配置同步，不能仅在机器人手机改一份本地值。

## 唤醒词当前支持范围

现有 App 路径：家长身份 → 成长 → 唤醒昵称 → 保存并等待机器人应用。灵敏度在家长身份 → 声音。机器人身份管理页目前只显示昵称并可测试唤醒。

`keywords.generate` 接受 2—6 个汉字，排除停止/继续等控制词，并校验模型支持的拼音 token；自动生成“昵称”和“你好＋昵称”两条唤醒词。当前不支持任意英文、数字或混合昵称。语音识别成功率仍须实机测试。

RobotRuntime 在会话和媒体播放都结束后切换待更新的词表。服务配置 ACK 与实际 KWS 词表生效不是同一时刻；V6 明确显示当前生效名和待生效名，正式实现需要增加词表实际生效的反馈。当前只改灵敏度不改变停止/休息口令。

V6 双入口指向同一设置：家长从设置进入；机器人在 PIN 管理入口内进入。保存依次呈现待确认、等待当前互动/播放结束、已生效；离线不允许保存，超时/冲突保留输入且不伪称生效。改名不改变其他设备品牌或助手，也不表示与“小爱”产品有联动。

## 本轮实际检查

使用以下命令直接调用当前服务词表生成逻辑（未改设备配置）：

```sh
PYTHONPATH=ai-service ai-service/.venv/bin/python - <<'PY'
from robot_service.keywords import generate
for name in ['小伙伴', '小爱', '小张', '停止', '小A']:
    try:
        words = generate(name)
        print(name, 'PASS', sum('@wake' in line for line in words.splitlines()))
    except ValueError as error:
        print(name, 'REJECT', str(error))
PY
```

结果：小伙伴、小爱、小张均生成 2 条唤醒词；停止、小A 被规则拒绝。仅验证词表生成，不是儿童发音、误唤醒率或在用 APK 的验收。

V6 的脚本使用 `node --check` 定向检查；本轮不编译或安装 Android，不操作另一任务正在测试的手机。当前 OpenSpec 仍保留儿童声学、家庭样书、长时稳定性和最终合并验证等未完成项，不能据此认定产品已通过全部验收。

### 需要修正的规则或防止重复算入的项目

1. **身份切换存在规范与实现差异。** docs08 规划切换身份时撤销当前安装凭据；当前 MainActivity.change 只切换 mode，并保留“返回已绑定家长端/已登记机器人”入口；V6 也写了“已有绑定信息会保留”。这不是凭空再加一个按钮能解决的问题。设计需要明确区分“返回本机已授权身份”和“解除绑定/更换用途”，独立提示认证、凭据和数据后果；不应声称现有实现已经遵循旧版撤销规则，也不在本轮擅自撤销真实凭据。
2. **图书语言仅中文/英文是用户已确认的收敛。** 旧代码的“双语”不是需要补回的遗漏。
3. **云端出站设置不能按旧建议补成可用开关。** 当前 schema 的 cloudText/cloudAudio/cloudImage 固定 False，health 返回 cloudEnabled=False，未接入云端供应商。首版展示本地处理与当前能力；是否增加云能力另行定义。
4. **标准/高品质两档仍只是设计假设。** 不能等同 Qwen/Kokoro 切换，不计入现有功能覆盖。逐句历史和机器人本机改名入口也保留上一轮“新增设计/待实现”的标记。
5. **不要扩大为本轮遗漏的功能。** 多儿童/异地管理、底盘跟随、音色克隆、任意歌词演唱、EPUB/Word 导入、持续看内页自动翻页，以及带全书引用的情节问答，按既有文档仍属后置范围；没有加入当前管理页不算缺陷。
6. **发布成功、音频就绪、完整离线下载是三个不同状态。** 该点归入上一轮“离线与换版”，本轮再次强调：服务 publish 返回固定版本，不证明所有音频已合成或已下载，更不能因为发布就自动打断孩子开始播放。
7. **“测试唤醒反馈”和“测试昵称识别”不可合并为一个成功结果。** V6 已有试叫说明，但现有硬件测试按钮主要检查表情/声音。语音命中率仍需现场试叫，不以词表生成或按钮唤醒替代。
