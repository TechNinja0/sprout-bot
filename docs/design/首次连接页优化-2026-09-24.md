# 首次连接页优化

首次连接页统一使用新版深浅主题、步骤进度、分组卡片、独立表单标签和全宽按钮。移除 JSON 编辑器，机器人连接的主流程只需 IP 与端口。

## 当前流程

1. 选择机器人手机，填写电脑 IP / 主机名与实际服务端口。
2. 点击“检测并连接”，App 自动检测服务、登记身份并保存连接信息；无需在电脑确认，也无需确认码或文件。
3. 设置并重复管理 PIN，授权麦克风/相机或选择稍后授权，进入小伙伴。
4. 家长手机通过机器人管理页生成的二维码绑定，配对文件导入仅作为备用方式。

管理 PIN 保护手机本机的管理入口，不是电脑端的访问密码。家庭服务采用“可访问即可登记”的首次连接方式；后续访问仍使用设备凭据，证书与服务身份固定校验、角色权限、家长配对确认不变。此前增加的电脑确认流程和双击批准工具已移除。

## 当前家庭服务

电脑局域网 IP 为 `10.2.8.88`，服务实际监听端口为 `8766`。APP、服务启动脚本与命令行默认端口统一为 `8766`，一般无需修改；地址以当前 Wi-Fi 网络为准。已有身份不需要重新登记。
