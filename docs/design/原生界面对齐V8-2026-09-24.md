# 原生界面对齐 V8

## 差异原因

先前 V8 实现把接口、数据与导航功能接入现有 Compose 页面，但没有完整迁移交互稿的组件结构。原生通用 Page + Action 以 12dp 纵向间距排列按钮，默认 Material 控件、独立调试入口和信息堆叠仍存在。之前的验证以接口、设备生命周期和可用性为主，没有把稿中布局逐页纳入断言，因此“功能可用”不能说明“界面已对齐”。

基准为本地最终 `robot-management-v8.html`，包括 V7 admin 和 V3 chat 的后续覆盖，而非最初截图。最终设备检查稿已改为有界本机自检和采集范围确认，不能误用早期四个分项检查卡片。原稿路径：`/Users/wangqiang/.codex/visualizations/2026/09/23/01a0ccea-e962-7b33-b573-81fcae3ec4a5/robot-management-v8.html`。

## 本次对齐

| 区域 | 原问题 | 修改 |
| --- | --- | --- |
| 标题栏 | 文本箭头、缺少右侧标识、标题偏大 | 44dp 返回点击区域、21sp 标题、34dp 标识，统一间距 |
| 机器人首页 | 所有入口为单列卡片 | 连接状态、运行摘要、双列常用功能、分组设置列表 |
| 服务器连接（双端） | 地址和诊断混排 | 服务名称/地址/身份验证/同步版本、折叠技术详情、检查与取消、更换连接入口；检查反馈就近展示 |
| 检查与调试 | 调试另开页面，没有页签 | 固定“设备检查 / 调试”分段页签；采集前确认范围、检查结果卡、折叠诊断 |
| 调试 | 输入框随历史滚走、纵向表单 | 固定底部文字/语音输入、自动播放设置、左右气泡、空态、新会话、记录入口；语音草稿确认和临时回放 |
| 设置 | 无分组、部分返回到首页 | 个性与外观、安全与设备、本机信息、身份与服务；子页返回设置 |
| 配对 | 配对和设备动作堆叠 | 说明与主按钮、待确认请求、已绑定家长分组；解除绑定确认 |
| PIN | 只有一个新 PIN 输入 | 当前 PIN、新 PIN、确认新 PIN；格式、一致性、原 PIN 校验 |
| 离线内容 | 点击列表直接播放 | 先进入内容详情，明确“返回小伙伴并播放” |
| 身份切换 | 直接进入连接材料页 | 独立身份选择，已有授权直接切换；未绑定再进入连接流程 |
| 教程与主题 | 零散卡片 | 分组折叠教程、主题单选列表，保留本机设置 |

真实连接状态、真实配置版本、空列表、使用限制继续来自设备和服务；不复制稿中的模拟成功、书名、分钟数或诊断结果。连接正常不承诺所有模型已就绪。配对继续使用已有真实二维码，不替换为装饰码。

## 尺寸与样式基准

以下为 HTML/CSS 与 Compose 源码的数值对照，不声称浏览器像素和 Android 物理像素一一相等。Android 使用 dp/sp 并尊重系统字体缩放；系统状态栏、导航栏与中文字体由系统提供。

| 检查类别 | 原稿规格 | 原生实现 |
| --- | --- | --- |
| 容器/边框 | 主面板圆角 20px、1px 边框 | 20dp、1dp；深色边线 #304449，浅色 #E1E9E4 |
| 区域间距 | 主内容左右 20px；页眉下 18px | 20dp / 18dp；详情行放入连续分组避免重复外间距 |
| 元素位置 | 左返回、右标识；首页两列 | 同结构；真机断言两卡标题同一横排 |
| 排版 | 标题 21px、行标题 14px、说明 12/13px | 21sp / 14sp / 12–13sp，明确行高 |
| 表单 | 输入圆角 13px；聊天输入与消息分区 | 13dp；输入固定底部，IME 内边距处理 |
| 按钮/图标 | 主操作 48px 高、14px 圆角、图标 20px | 最小 48dp、14dp 圆角、矢量图标 20dp |
| 页签/分隔 | 页签外 13px、内 10px；连续细分隔线 | 13dp / 10dp；边线采用对应主题色 |
| 连接状态 | 深色绿色 #193C30 / #9DE3B9，失败 #422A2A | 同色值；浅色采用 #E7F4EB / #19734F、#FCEDEA |

## 验证方法与边界

设备为华为 OXF-AN10 / Android 12，实际 density=480、font_scale=1.0；1080 物理像素宽对应 360dp。参考稿 410 CSS px 的外框是演示容器，不把模拟状态栏和外框画进 Android。截图保存在 `ui-audit/artifacts/design-align-20260924/files/design-alignment/`（不提交设备资料）。

新增 `DesignAlignmentTest`，使用当前已配对服务，临时 PIN 和主题在 finally 中恢复，不修改家庭配置。机器人流程覆盖双列位置、连接明细及折叠、真实检查反馈、未确认不能启动自检、页签、真实模型回复及回放入口、调试记录、录音中切换页签、PIN 字段、返回路径、两套主题、配对列表、教程。家长流程覆盖连接页以及记忆/摘要/成长/声音/隐私/清单/英语计划/使用安排导航。此轮不把“点击回放”冒充人工听感验收，不重复长测或声学验收。
