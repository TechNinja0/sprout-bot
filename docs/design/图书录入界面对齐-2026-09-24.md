# 图书录入界面对齐

## 原因与设计依据

V8 交互稿已有录入页 `gBookEdit()` 和正文导入页 `gImport()`：书目信息折叠、素材分组入口、具体导入方式放在二级页。原生实现将这些操作平铺为同等强调的按钮，步骤栏也随长表单滚走，造成信息层级与交互稿不一致。

设计来源：`/Users/wangqiang/.codex/visualizations/2026/09/23/01a0ccea-e962-7b33-b573-81fcae3ec4a5/robot-management-v8.html`。

## 已实现

- 录入首页：草稿状态、名称、版本与语言；语言保留中文/英文下拉；其他书目信息折叠。
- 素材与正文：封面、正文、逐页校对、已有音频四个分组入口。
- 封面二级页：拍摄封面、从相册选封面。
- 正文二级页：单页拍摄、连续拍摄、批量选图、PDF/文本、手工添加文字。
- 音频二级页：选择/替换录音、试听已上传原音频。
- 导入任务二级页：当前图书的进度、刷新、按状态重试/取消、查看已录入页、继续录入。
- 顶部步骤固定；录入首页底部固定“保存草稿”和“下一步”，区分主次操作。
- 页面、步骤、书页切换重置滚动位置；二级页返回保留内存中的草稿，退出编辑仍有未保存提示。
- 使用现有主题组件，适配浅色与深色。
