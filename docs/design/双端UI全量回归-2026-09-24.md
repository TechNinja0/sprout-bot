# 家长端与小伙伴端 UI 回归

基准：`robot-management-v8.html` 的最终 V7 功能覆盖与 V8 主题覆盖，不能只比较 HTML 中早期同名函数。基准文件 SHA-256：`29277654bb291d5f95d329cad5292bdcddd968baa457603aabb12fd6b4764ed4`。

设备：Huawei OXF-AN10 / Android 12，1080×2400、480 dpi；同一部真机切换独立机器人、家长身份。验收服务使用 `ui-audit/artifacts/full-ui-20260924/runtime`、端口 8876，原家庭服务端口 8765 的资源和配置不参与写入测试。测试前备份本机加密身份、PIN 与主题，交付前恢复。

## 为什么此前仍有差异

1. 原生端主要按功能入口实现，若干页面仍使用旧的连续表单和默认 Material 控件，未同步最终稿的列表、详情、分组与层级。
2. 原交互稿多次覆盖同名页面，早期的文字调试、资源录入、设置菜单与最终 V7/V8 已不同。
3. 之前验收偏重接口、硬件和少数关键页面，缺少完整页面路径、返回行为与空状态的 UI 回归。
4. 某些稿中交互确实缺少实现，例如已有播放清单编辑、图书校对页列表、提示词版本页、资源库的导入任务入口。

## 本次修正

- 统一双主题配色、独立表单标签、填充输入框、13/14/20 dp 圆角、下拉框、分组行、线性图标与底部导航。编辑子页不堆放底部 Tab；家长首页、资源库、记录、设置保留对应导航。
- 家长首页分别显示家庭服务器与机器人在线状态，展示真实今日用量与播放状态；内容与安排使用分组入口。
- 家长检查与调试增加双页签；家长手机不会冒充机器人硬件检查。
- 资源库采用搜索与单一下拉筛选，含收藏、草稿、发布、下架、下载状态；新建资源移入对话框，补齐导入任务、电脑目录导入和阅读指南入口。
- 图书录入采用三步条、书目折叠区、页列表及单页编辑；增加删页确认、发布校对门槛、实际试听后确认与内容变更检查。修复第二个 `BackHandler` 绕过未保存书稿提示的问题。
- 偏好与记忆、播放清单、英语计划改为列表与编辑页，包含空状态、审核、未保存提示、删除确认。
- 播放清单新增 `PUT /v1/playlists/{id}`：家长授权校验、已发布资源校验、保持清单 ID，避免英语计划引用失效。
- 对话记录增加陪伴/调试分类、会话列表与详情、使用记录入口。提示词预览和历史版本成为独立页。
- 维护、空间、备份、绑定分开展示；备份选择与执行恢复分为两步。恢复按钮需文件及管理员凭据。
- 首次设置分为用途选择、连接验证、权限完成；空材料不能提交，等待家长配对可取消；补充忘记 PIN 的管理员恢复入口。
- 修复按页面名硬编码返回导致跨入口跳错页面的问题，改为保留实际进入路径。
- 修复清理副本后下载状态仍显示已下载：等待下载任务停止再清理，回报 `removed` 并更新离线词表。

## 验证方式与边界

- 视觉核对采用最终 HTML/CSS 与 Compose 参数、真机截图、层级与交互断言。没有声称像素级 SSIM 对齐。Android 状态栏、键盘、权限弹窗、相机与文件选择器使用系统界面。
- 界面中的服务状态、用量、下载与模型回复来自实际服务；没有把稿中的“18 分钟”等示例数值带入产品。
- 使用同一部 Huawei 切换两种身份；尚不等于第二部家长手机现场扫码或儿童声学/音质验收。
- 书页相机/选图测试由系统 Intent 返回原创图片夹具，再实际上传并执行 OCR；不声称完成真实纸书拍摄质量测试。
- 原稿支持部分“页面”用系统选择器、折叠区或确认对话框承接；业务入口和结果可达性分别核对。
