# 家庭实体验收执行表

这是一份待执行记录模板，**没有填写任何通过结果**。对应[产品需求§7和§9.6](../01-产品需求文档.md)、[逐项验收矩阵](逐项验收矩阵.md)中仍缺真人、实体书和实物证据的条目。它不改变原始标准，也不替代当前自动长测。

## 开始前记录一次

| 字段 | 实际填写 |
| --- | --- |
| 批次、日期、执行人代号 | 待填；不需要孩子姓名 |
| 生产APK SHA256、服务源码清单 | 待填；引用本批冻结清单 |
| 文本/视觉/ASR/TTS版本 | 待填；不能混用不同模型批次 |
| 手机型号/系统、电脑配置 | 待填 |
| 家庭Wi-Fi、是否USB转发 | 待填；USB结果单列 |
| 音频实际路由、音量、蓝牙状态 | 待填；耳机结果不能代表手机外放 |
| 昵称、灵敏度、相机权限、使用安排 | 待填；测试结束恢复实际原值 |
| 距离、环境声、是否充电 | 待填；不要用“安静”代替观察记录 |

同一批次保持配置一致。换模型、昵称、声路或影响相关功能的代码后，新建批次，不覆盖原失败。孩子可随时停止，分多次完成；不能把未执行的次数填成失败或成功。默认只记录事件和最小摘要，不保存整段录音、环境照片或聊天全文。

每次使用以下行式记录，复制足够行数即可：

| 用例编号 | 材料/场景代号 | 开始时间 | 预期 | 实际现象 | 成功/失败/未执行 | 脱敏证据位置 |
| --- | --- | --- | --- | --- | --- | --- |
| 待填 | 待填 | 待填 | 待填 | 待填 | 未执行 | 待填 |

## S：儿童语音与会话

| 用例 | 执行方法 | 原始标准及记录重点 |
| --- | --- | --- |
| S01 唤醒30次 | 目标孩子在0.5—1米叫实际昵称，每次回到待机再开始；不注入转写，不用触摸代替 | 至少27/30成功；分别记距离、是否响应、是否截断紧接的问题 |
| S02 连续对话10组 | 每组5轮，首次叫昵称，其后在回答结束30秒内直接提问；话题可为孩子熟悉的颜色、动物、日常英语 | 至少9/10组完成；上下文正确、无需每轮再叫昵称。成人或合成输入另记，不计儿童样本 |
| S03 播放中停止 | 回答播放中10次、故事播放中10次，每组覆盖昵称打断、“停一下”“休息吧” | 逐条记录命令及响应；昵称后可提问、暂停保留进度、休息退出，旧回答不得复播。双击只记兜底，不计语音成功 |
| S04 背景声2小时 | 记录电视/音乐等实际背景来源和时段，保持待机及实际声路；记录谁曾主动发令 | 误唤醒不超过1次；正常有人叫醒单独记。无法判断来源的事件标“待确认”，不能直接归零 |
| S05 等待与会话上限 | 回答真正播完后不说话、等待中续问、连续达到10分钟，各5次 | 30秒等待和10分钟上限符合规则；机器人自己的外放和背景声不应续期。真实静默失败保留，不能用关闭麦克风补通过 |
| S06 状态理解 | 让孩子观察待机、倾听、静音、限时和故障，再记录是否知道现在能否说话 | 记录可观察行为，不推断智力、心理或学习成绩；家长能从管理页查到实际原因 |

S05当前已有未通过证据。应记录现场是否确有其他人在说话、是否外放、VAD/KWS事件时间；仅凭事件次数不能判定一定是噪声或误检。若需额外录音定位，另行明确采集范围与保留方式，不能默认开启长期环境录音。

## B：家庭图书

先建立10本不同实体书的名单，每本只用代号B01—B10引用家庭库ID、语言、版次和已发布版本。至少包含中英文、同系列或相似封面；不能用同一本书拍10张照片冒充10本。确认正文来自真实素材，并完成家长校对和试听。

| 用例 | 执行方法 | 原始标准及记录重点 |
| --- | --- | --- |
| B01 建库 | 分别使用照片、扫描PDF、文字PDF和已有文字；实际执行失败重试、重排、补页及保存后恢复 | 来源与页序正确；只修相关页；未审核内容不发布。格式夹具检查与实体书OCR质量分开记录 |
| B02 清晰封面30次 | 10本各3次，孩子展示实体封面并发出读书请求；记录实际命中版本 | 至少27/30正确定位，未经消歧播放错书不能通过 |
| B03 异常20次 | 同名/异版、同系列难分、模糊/遮挡、未入库、草稿/仅封面等，共20次；每次预先写清应出现的结果 | 不编正文、不播错版本；应澄清或说明不可读原因。模糊重拍后正确命中不抹去首次结果 |
| B04 原文与音频 | 至少3本，覆盖中英文，每本检查开头、中间、结尾和分页边界；对照审核正文及实际声音 | 不漏段/重段、不读错版本；读音、语速和音色人工试听。只抽样就写“抽样核听”，不能写“全文核听通过” |
| B05 进度和版本 | 实体使用时暂停/继续、下次续读、前后页；编辑发布新版本再点播 | 同版正确续读，新版不套旧偏移；解释后等待“继续”；实体翻页不自动跳页 |
| B06 撤回与备份 | 播放中下架；离线设备下架后重连；旧清单点播；恢复旧备份 | 在线停播、旧清单不能绕过状态、离线显示待同步、恢复不自动发布被撤回内容 |

## V：当前物体和视觉歧义

提前登记20件家中实际常见物品的V01—V20代号、正确名称和可接受近义词。例如可从杯子、勺子、球、积木、毛巾等已有物品选择；这只是选材建议，不是已识别结果，也不需要购买材料。不要把屏幕显示的圆形或示意图计为实体物品。

| 用例 | 执行方法 | 原始标准及记录重点 |
| --- | --- | --- |
| V01 20件识物 | 逐件展示，问“这是什么”；部分追加“这个怎么用” | 至少16/20正确；区分实际观察与一般用途，不凭外观确认食物安全、药品用法或人物身份 |
| V02 歧义10次 | 多个可能目标、遮挡、偏暗、偏远等，预先登记可接受澄清 | 至少8/10澄清或拒答；请求调整后新一轮单独记录 |
| V03 A换B 20次 | 看过A后换成B，问“这个/看看现在”；另问“它”核对最近已确定对象 | 新指代用当前画面，失败时不能回用旧A；历史追问可用文字观察，不自动新传图 |
| V04 相机生命周期20次 | 唤醒与退出各20次，包含休息、后台、权限失败和长媒体 | 唤醒发起相机；退出1秒内开始释放，迟到帧不使用；长媒体不持续保活相机 |

## N：家庭网络、时间与恢复

在两部实际Android手机和家庭Wi-Fi上验证连接、配对、配置冲突/离线和应用确认，记录两端身份及版本；单手机切换身份、USB转发不计双机同网证据。

使用时间分别记录19:59→20:00、08:59→09:00、额度用尽及跨午夜。断网、进程重启、系统重启和系统时间变化分开记，不能相互替代。系统重启/改时钟须在家长可解锁、可恢复配置的现场执行；自动无人值守长测不做这些操作。

完整延迟按30轮语音、20轮视觉测量，从孩子说完到手机首句实际出声，分别记录可获得的VAD、网络、模型和播音时间。目标为语音中位数4秒内、视觉中位数6秒内/P95 12秒内。服务端热态基准另列，不能替代手机端结果；首次加载单独记录。

## 汇总与处理

每类汇总实际执行数、成功数、失败数、未执行数和待确认事件。失败填写复现条件、关联日志和修复版本；修复后重验受影响场景，保留前后两批结果。长测以实际完整时长、断言结果及资源趋势为依据，不因进程还活着就填通过。

证据存入家庭私有目录，不上传公开issue。对外报告只引用代号和脱敏摘要。所有未执行或来源不明的结论保持待验；满足对应标准后再更新[验收证据索引](验收证据索引.md)及OpenSpec任务。
