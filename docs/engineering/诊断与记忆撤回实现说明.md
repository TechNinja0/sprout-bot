# 诊断与记忆撤回实现说明

本说明补齐原始《整体产品细节》§4.2/§5 和 PRD §3；属于现有需求收尾，不扩大默认采集范围。具体测试版本与结果见[自测记录](自测记录.md)。

## 家长如何排查问题

家长手机的“维护”和机器人 PIN 管理页均提供“刷新脱敏诊断”和“保存脱敏诊断”。先刷新，再通过系统文件选择器保存 JSON。服务端 `/v1/diagnostics` 校验身份，只返回当前绑定机器人的状态；家长端不会远程启动摄像头或录音。每份报告带生成时间，心跳状态是最近一次上报，不能当作持续在线观测。机器人超过 15 秒未心跳显示离线。

报告只包含：服务/App/协议版本、Android API 级别、导出手机的权限、配置目标/已应用版本、最近心跳及状态、固定分类失败计数、模型可用性布尔值、剩余存储空间，以及本机执行过的自检结果。自由文本状态不在白名单时输出 `unknown`。报告不含设备身份、地址、证书指纹、令牌、PIN、孩子档案、记忆内容、书稿、原始音视频或识别文字。

在线和模型可用只能说明连接及模型文件/服务条件，不等于识别准确、扬声器可听或摄像头识物效果通过。报告可直接作为问题描述的附件；完整资源库备份是另一功能，含私人正文，不应附在公开 issue 中。

## 机器人本机有界自检

亲自在机器人 PIN 管理页点击“开始本机自检”，页面先明确说明采集范围。它复用唯一 `AudioInput`，不建立第二个麦克风实例，也不创建孩子会话。正常关键词和聊天断句在自检时停用。

1. 至多录制 48,000 个 16 kHz 单声道 PCM 采样，即 3 秒；等待硬件启动最多 8 秒。显示采样数、RMS 和系统 AEC 是否启用，不据此判断识别成功率。
2. 临时音频发往已配对的家庭 ASR，客户端等待最多 10 秒。识别原文仅在管理页临时显示，开始下一次自检、停止或离开页面即清除，不进入诊断文件，也不进入聊天或长期记忆。
3. 相机等待最多 4 秒，必须收到启动后的新帧；只返回 `fresh-frame`/失败原因，随后释放相机、清空帧。家长关闭相机或缺少系统权限时跳过。
4. 通过真实 `AudioTrack` 播放原创半秒测试音，检查实际播放头进度。遵守当前系统音量、家长音量上限及音频焦点；`played-unconfirmed` 表示输出链路已推进，需现场听感确认，声音可能走当前连接的耳机。

总自检上限 30 秒。禁用时段、额度、家长静音、异常时钟或严重温控阻止启动；运行中同样检查。停止、后台、退出管理页及音频焦点丢失取消采集与输出。自检没有专用放行权限，不能绕过使用限制。原始 PCM/画面仅临时驻留内存，不写文件。取消会立即释放本轮设备；已经发出的 ASR 请求稍后返回时，只能丢弃结果，不能再次释放重新开始的孩子会话所持有的麦克风或相机。

## “不要记这个”的处理

“记住我喜欢……”只创建待审核偏好。紧接着在同一会话说“不要记这个”，服务端删除这条明确候选、清空内容并写删除墓碑；其他已经批准的兴趣保留。候选指代只保存在内存，最多 10 分钟、100 个会话引用，任何中间话轮或家长编辑都会使引用失效。

没有明确指代时，不擅自删除不相关内容：现有待审核/已批准偏好转为 `suspended`，立即退出个性化检索，清空当次聊天上下文及引用，提示家长逐条核对。重启仍为停用；只有家长明确批准的项恢复使用。家长“记忆”页显示中文状态、最小来源及时间，并提供批准、编辑、拒绝和删除。

“删除全部记忆”等明确全量指令才调用全部删除。每次儿童撤回保留最多 20 条无正文的处理事件（动作、数量、时间），由仅家长可用的 `/v1/memory-actions` 展示。事件不含原偏好、摘录或录音。服务端更新记忆代际，使正在等待的旧模型回答失效；所有当前上下文清空。

旧资源库备份恢复先应用删除墓碑，已删除内容不会复活。可恢复的偏好都回到待审核状态，不能自动批准，停用内容也不能借恢复重新参与对话。本轮使用已有 `meta` 和记忆状态列，不增加数据库版本。

## 相机启停声音

`CameraInput.ready` 只在收到当前代际的真实画面后置位，停用立即清除；启动请求不算就绪，迟到分析帧不能恢复关闭状态。运行层观察此状态，播放原创 120 毫秒升调/降调双音，分别表示启用/停用；不使用模型、网络或其他产品音频。

提示音独立于正文音轨，不修改书籍位置。收音的回声标记覆盖短音和其后 250 毫秒，保留首句采样；孩子正在说话或开场回应正在播放时让出声音，最多等 2 秒，超时记为 `speech-priority`，不在很久以后补响。麦克风首句/AEC 的声学效果仍需真实儿童验收。

系统静音、家长音量 0、禁用、后台、温控、强制停止优先于提示音；不为了播放停用音重新开启会话。相机未获授权或启动失败不能播放启用音。普通话轮切换不重复播报相机已启用；自动正常结束有关闭提示时替代原无语义结束铃。PIN 自检只使用自己的可见状态和测试音，不触发儿童会话的相机提示。

## 其他原始细节收尾

相机已由家长允许但系统权限拒绝或启动失败时，使用本地固定语音“相机暂时用不了，我们可以说话。”；不开云端，不强制结束语音会话。开场首句仍保留采样并清理已知提示回声。该资源由 `generate_prompts.py camera_unavailable` 生成，来源与配置记录在 prompts/provenance.json。家长主动禁用相机不作为故障重复播报。

图书草稿详情新增 `pageOrderWarnings`，只比较同章相邻、明确的数字印刷页码，提示跳号、重复或逆序；空白、图版文字、无法解析页码或跨章时不猜测。提示只供校对，不自动补页、拒绝节选或修改正文。编辑后保存刷新可更新提示。

所有 `Api` 业务请求先核验已固定证书下的服务身份及协议版本1，健康结果缓存至多15秒；不兼容版本在写请求发出前拒绝并提示升级。连接材料显式声明其他协议也拒绝。兼容检查不迁移家庭数据，不关闭证书验证；已下载内容仍按既有离线授权和时限处理。

“声音”页提供昵称唤醒低/标准/高三档，逐关键词阈值分别0.35/0.25/0.15，默认保持原0.25；只修改昵称及“你好＋昵称”的词条，停止/休息等控制词不变。改名或修改灵敏度的词表在会话结束后切换，避免打断首句。实现依据 [Sherpa官方逐关键词阈值说明](https://github.com/k2-fsa/sherpa/blob/master/docs/source/onnx/kws/index.rst)；更敏感可能增加误触发，各档不是儿童准确率承诺。实际模型已接受三档词表与数字静音输入，仍需实地声学测量。

同页提供委屈/哭泣的轻柔/普通表演强度，默认轻柔；仅改变眉形、泪滴和嘴部表现，不改变会话、采集、权限或停止规则。减少动态效果和关闭逗趣继续独立生效。

R03的“别看了”和“不要拍了”均映射到本地 `camera_off`；服务同时接受“关闭相机”。这些命令只关闭本次会话相机，普通语音可以继续；下一会话重新遵循家长默认策略。词表修订随下次词表同步取得，已运行旧客户端可重新进入机器人身份取得最新版；不要通过改变昵称来绕过同步。
