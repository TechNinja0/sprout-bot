# 图书音频准备与连贯播放

## 方案与使用方式

发布后在家庭电脑后台按阅读顺序生成音频，机器人播放当前段时提前获取下一段。使用现有本地 Qwen3-TTS/Kokoro、SQLite 和按发布版本保存的 WAV，不引入云端、Redis 或第二份模型。家长端资源详情显示准备进度；准备失败可重试，已生成的段落保留。准备完成后播放无需首次合成等待；准备中也允许播放，未生成段落按需合成。

设计参考：Amazon Polly 的[长文本异步合成并保存结果](https://docs.aws.amazon.com/polly/latest/dg/asynchronous.html)，Android 的[相邻媒体预加载](https://developer.android.com/media/media3/exoplayer/preloading-media/preloadmanager)。采用这些架构原则，不接入对应云服务或迁移整个播放器。

## 服务端

- `audio_jobs` 独立保存每个发布版本的任务，与发布快照和发布回执同事务提交；重复 requestId 不重复入队。
- 默认启用后台工作循环，一次处理一段，每段后让出一秒；多本书轮转，先生成节选范围说明再生成正文。上传原录音的资源只生成必要的范围说明，不替换原录音。
- 启动时补齐存量已发布资源的任务，恢复 processing 任务，按实际文件核对完成量。ready 版本文件丢失时重新入队；不会重做已有缓存。
- TTS 仅一个实例、一个推理槽位：实时对话 > 当前播放/试听 > 批量准备。同优先级 FIFO，沿用有界队列和超时。正在执行的单段推理不被抢占，因此后台工作仍可能影响一次对话的首句延迟。
- 背景队满返回 429 时延迟两秒再试，不消耗失败次数。临时模型错误按 10、20、40、80 秒退避，第五次失败停止并可手动重试；引擎不匹配、非法参数、容量不足直接显示失败。
- `(revisionId, segmentId)` 合并并发合成请求；单个请求取消不影响其他请求，服务关闭时统一取消。文件通过现有容量校验和原子替换落盘；下架与写入校验互斥，删除不会被在途合成重新创建文件。
- 换版后停止旧版未完成的批量任务；已开始的一段可以结束。旧版当前阅读仍遵守已有版本规则。正文、音色和模型指纹以发布快照为准。
- `ROBOT_PREPARE_AUDIO=0` 可停用自动工作循环，保留按需合成；修改环境变量后重启服务。正常使用保持默认值 1。
- 运行方式仍为一个服务进程。任务持久化用于重启恢复，不是跨机器的分布式任务租约，不支持多个服务进程共享同一个运行目录。

接口：

- `GET /v1/resources/{rid}/audio-preparation`：需要设备凭据，返回当前发布版本的 `revisionId/state/completed/total/error`。
- `POST /v1/resources/{rid}/audio-preparation/retry?revisionId=...`：仅绑定家长可重试失败任务；拒绝过期版本，重复请求不重复创建任务。
- 原有音频接口和下载协议保持兼容，返回已有 SHA256 校验头；没有缓存时仍按需生成。

## Android

`playWithLookahead` 最多持有当前段与下一段，范围说明也加入同一播放顺序。预取异常先保留，到消费对应段时才抛出，避免下一段失败截断当前段。暂停、跳页、换书取消作用域和对应 OkHttp 请求，不取消心跳等其他请求。只有真实播放结束才推进段落与进度，预取完成不改变阅读位置。

分段导航、嘴形、暂停和离线下载沿用现有 AudioTrack 路径。2026-09-25起，合成分组与书页分开：成功对齐的跨页声音按真实采样位置拆回逐页WAV，保留现有导航与离线协议；拼回PCM与合成原音频逐字节相同。AudioTrack仍按段播放，不宣称手机端采样级无缝。

## 分页、连续朗读与试听缓存（2026-09-25）

- 图书保留原图、正文、页码。单页优先按句末/从句分成至多180字的小段，避免先前正则在可用语义边界前硬切。
- “跟书朗读”逐页合成，非静音页末至少保留450ms数字静音；“连续故事”可将同章节相邻短页组成一组，最多4页、120字，跳过页/空白页/多段长页及 `breakBefore` 场景标记阻断合并。
- 合成组只生成一次，再用已有本地faster-whisper-small逐词时间戳验证正文；中文同音字须在各自上下文中拼音和声调都一致，英文/数字不作同音放宽。置信度须≥0.6，页界在合法词间优先取中点，否则寻找最近的连续20ms低能量窗口（PCM16峰值≤32、RMS≤16）。低置信度、异音、页界落在词内部、过长或无安全静音间隙时，整组回退逐页合成。缺少本地small直接回退，不下载模型。
- 清单保留每段 `pageId/groupId`；每组 `.alignment.json` 保存页与音频的起止毫秒、模式、大小和哈希。页界不按字数估算，原文没有改写。
- `GET /v1/resources/{rid}/speech-plan?expectedVersion=N` 返回正式分段；家长专用 `speech-preview/{segmentId}?expectedVersion=N` 生成/返回相同音频。版本过期拒绝试听。
- 试听缓存按资源、声音指纹、阅读模式、分组正文与生成版本隔离；修改 `Page.synthesisVariant` 重新生成相关组，其余组继续复用。发布复制合格缓存，不再随机重做一次。音频组最后写入哈希清单，未完整写入或校验损坏的组不能当成可用音频。
- 删除图书清理其试听缓存；下架/删除与生成完成复核配合，防止迟到生成恢复已撤回的发布音频。修改任何朗读规则须升级分段版本，旧发布音频保持原声。

## 验证

真实模型冒烟使用隔离临时资源库，不修改家庭书籍：

```sh
PYTHONPATH=ai-service ai-service/.venv/bin/python scripts/book_audio_smoke.py
```

2026-09-24 本机 Qwen3-TTS 实测：发布返回 2.36 ms；两段音频后台生成分别为 9.598 s（含冷加载）、1.275 s，发布至全部就绪 12.946 s。就绪后两次读取为 5.40 ms、4.02 ms，音频长度分别 1.68 s、1.92 s。重建服务对象及生命周期后复用缓存，没有加载 TTS 子进程。报告和 WAV 位于 `.artifacts/book-audio-smoke/`，不提交家庭数据或二进制音频。

上述读取时间为进程内 HTTP，不包含局域网传输与 Android 音频输出，不作为真机段间停顿保证。自动测试覆盖任务恢复、缓存命中、并发去重、单请求取消、下架/删除竞态、版本隔离、权限、容量失败、退避重试和有界预取。
