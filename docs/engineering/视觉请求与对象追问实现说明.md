# 视觉请求与对象追问

本说明对应原始 PRD R07—R09 的修订实现。当前代码已有取图边界、结构化观察和未确定对象的追问保护；已选择4B视觉/2B文本，真实物体验收仍未完成，不能据此宣称视觉功能已经达标。当前结果见[自测记录](自测记录.md)。

## 手机何时发送画面

`android-app/core/VisualIntent` 判断是否明确询问眼前物品。例如“这是什么”“这个怎么用”“你看我拿的什么”“看看现在”请求新帧；“这个故事真好听”“不要记这个”“这个词怎么用”不请求。明确的英文物品问题也支持，声音、故事指代和停止请求排除在外。

“它怎么用”“刚才那个是什么颜色”先使用当前会话最近一次视觉的文字观察。“这个”与“它”因此有不同含义：前者重看眼前，后者继续刚才的话题。封面读书走独立的 OCR 和家庭书库查询流程，不由通用视觉模型生成书籍正文。

实际取帧仍受 CameraX 就绪、采集时刻、家长授权、使用安排和会话代际约束。退出、停止或迟到返回不能重新打开相机。画面不写入聊天历史；家长主动导入封面/内页属于另一条持久资源流程。

## 服务怎样回答

`ai-service/robot_service/vision.py` 定义有界 JSON：完整对象数量和名称、是否看不清、是否需要澄清、可见观察及一般用途。新图请求只给模型当前图片和问题，避免旧对象或普通聊天提示干扰。结构不合法时返回模型不可用，不把原始 JSON 读给孩子。

系统按以下规则生成最终口头回答：

1. 近乎全黑的图片先拒绝识别：至少98%的像素亮度低于16时，请孩子调整光线。此规则只覆盖近黑，不等于可靠检测全部模糊或遮挡。
2. 模型认为看不清或没有对象时，请调整位置或光线，不猜名称。
3. 指向不明且存在多个对象时，询问具体哪一个；安静性格不能删除必要澄清。
4. 对象明确时先说观察；询问用途再补一句一般知识。模型不能据此确认药品用法、食物安全或人物身份。

对象数量仍来自视觉模型，应用校验不能保证其语义正确。例如当前2B候选曾把勺子与勺柄拆成两个对象；这属于实测失败，不能通过为该例硬编码排除“手柄”来冒充模型能力提升。

## 追问和失效

会话只保留最近观察文字、有限对象名和是否已经明确指向。若上次没看清，孩子再问“它怎么用”仍提示调整画面；若有两个候选，孩子可以明确说名称、唯一颜色或“第一个/第二个”。确认前不让普通对话模型随意把“它”猜成机器人或其他物品。

已明确对象的代词追问也会向文本模型明确传递对象名，避免上一句只说用途时丢失指向。用途首句由已识别对象名构成“看起来是……”，后一句标明一般知识；模型没提供用途字段时明确说还不确定，不把观察当成用途保证。

每次新视觉请求立即使旧参照失效，即使本次相机关闭、没有图片或图片无效，也不能继续拿上次对象作答。上下文沿用当前会话10分钟过期与记忆撤回规则，不进入长期记忆或资源库。

## 维护和验证

同一原创圆形、勺子、双图形、近黑图比较中，2B把勺柄独立计数；4B识别为单个勺子，保留双对象澄清。4B首次请求25.886秒；补强字段说明和对象上下文后的热态颜色3.335秒、用途4.106秒、歧义3.648秒，黑图规则0.005秒。它们是服务请求耗时，不包含手机收音、网络及TTS出声，不冒充PRD完整视觉延迟或20件实物验收。

部署需分别安装 `qwen3.5:2b` 与 `qwen3.5:4b`，并开启可选启动预热。视觉模型使用[Qwen官方4B模型](https://huggingface.co/Qwen/Qwen3.5-4B)的Apache-2.0权重，经[Ollama 4B发行物](https://ollama.com/library/qwen3.5:4b)分发；项目固定具体清单和文件哈希，不能自动追随可变标签。两个模型使用同一个有界对话槽，避免同时推理挤占家庭电脑；队列和实际内存/温控继续接受长测。

组合服务50轮检查已完成：30轮语音中位数2.387秒、20轮视觉中位数4.507秒/P95 5.45秒；固定词义与颜色检查50/50符合。包含真实ASR和首句TTS，输入仍是原创合成声音/图形，不包含手机拾音/VAD、Wi-Fi传输和物理出声，完整产品延迟仍按原PRD另验。

- 核心规则：`VisualIntentTest` 覆盖明确请求、普通指代、关闭/遗忘及历史对象。
- 服务：`test_visual_dialogue.py` 覆盖结构输出、用途、澄清、候选选择、全黑前置拒绝、无新图导致旧参照失效及不保存图片到历史。
- 华为：`VisualRequestPrivacyTest` 使用实际 CameraX 新帧检查网络请求是否附图；语音转写/模型回复注入，因此只证明请求边界，不是实际识物准确率。
- 模型比较：固定同一批原创图片和同一请求结构，保留原始输出、候选名称及耗时；候选下载不自动改变生产配置。变更正式模型前更新许可与模型层哈希，再验证服务能力、预热和同版本端到端链路。

真实20件物品、10种歧义场景、A换B以及手机到出声的视觉延迟仍须单独验收。合成圆形、勺子示意图和黑图用于发现实现缺陷，不能计入实体物品指标。
