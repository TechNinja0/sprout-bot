| R13 分页校对和失败恢复 | `imports`逐页失败/取消/重试/旋转/替换及版本保护；page_import测试、华为导入UI | OCR质量需原书逐页人工核对，不承诺自动无错 |
| R14 元数据与朗读范围、质量提示 | 书名/别名/版次/作者/出版社/来源、页码章节；原图对照、校对正文、整页不读；OCR质量与数字页序提示 | 当前正文编辑决定实际朗读稿。页码/章节元数据不自动混入正文；页眉、拼音、脚注若被OCR放进正文，家长须在校对稿保留或删除；没有自动分层识别器，不应宣传自动过滤所有附属文字 |
| R15 草稿与原文真实性 | OCR仅生成草稿；`publish`强制逐页审核；无正文不发布；无字书可由家长明确填讲述稿及来源 | 模型不会自动补写缺失原书；翻译/改写应人工另建资源并标明来源，不冒充原版 |
| R16 完整/节选与试听 | 发布完整范围或节选说明、试听确认；独立scopeNotice分段音频/同版离线清单 | 测试确认字段和音轨不替代家长实际试听 |
| R17 显式看封面选书 | 服务book意图→请求后新帧→OCR→库内检索；不持续扫描；补技术文档“讲这本书/讲《书名》”别名 | 实体封面匹配率尚未通过；下一本书和取消的代际规则由BookWorkflowTest覆盖 |
| R18 报书名、候选、续读 | `offerBooks`、有界口头选择、同版继续/从头；ISBN/版本优先、候选撤回/过期 | 原创书控制流程已测；真实同系列/中英版封面样本不足 |
| R19 不可读原因 | `lookup`区分未入库、未发布、缺正文/下架，OCR重拍、相机不可用、网络失败各自说明 | 不返回草稿正文或让LLM补书；现场语言理解另验 |
| R20 原文与解释分离 | `segments`直接按审核正文分段，TTS/缓存旁路LLM；插话后等待继续 | 通用短回答不等于整本情节问答；02§10.6已将带段落引用的书本问答明确后置 |
| R21 页章导航与进度 | ReadingNavigation、按版本/页段定位、重复页码澄清、无页码顺序说明；ProgressOutbox及BookWorkflowTest | 运行对象/进程恢复已测，不冒充OS重启；未映射页码不能猜偏移 |
| R22 不自动跟实体翻页 | 没有持续内页跟读；下一页口令及独立相机超时 | 不能宣传孩子翻页即自动跳页 |
| R23 音色/版本/完整离线 | 固定ttsProfile、全文/节选全部音频哈希校验、缺段拒绝混声；ResourceVoiceRevisionTest | 人工中英文关键页读音/音色听感仍待验；非完整缓存不标离线可读 |
| R24 草稿更新不覆盖已发布 | 版本事务/并发校验；编辑与新发布创建新快照，立即下架可撤回旧内容 | 真实编辑/试听习惯仍需家长使用验证；不把正常改版当撤回 |
| R25 通用资源及清单 | 图书、故事、歌曲、英语短句统一审核生命周期；清单引用ID并验证可播放状态 | 歌曲需真实录音，文本TTS不冒充演唱；自然衔接与迟到进度有真机记录 |
| R26 撤回删除导出恢复 | 下架版本墓碑、离线待同步、素材与派生音频删除；导出库/恢复为待审及记忆墓碑 | 离线不承诺即时删除；家庭真实备份/恢复操作及跨设备网络环境仍待验 |
