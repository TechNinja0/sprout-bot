# 语音一致性与短页绘本优化自测（2026-09-25）

## 已完成的行为

- 新配置默认自然语气，故事跟随回答；家长端新建图书可跟随机器人声音或使用独立声音。跟随关系在保存草稿时解析为快照，已发布内容不会随设置变化换声。
- 对话首句优先，后续短句合并；一次回答固定声音和语言，保护小数、缩写、引号等边界。
- Qwen固定采样参数及可复现候选；相同输入的生成seed不受播放倍率影响。0.7—1.3倍率改由PyAV atempo变速不变调，加入±3dB有界有声帧RMS增益和峰值保护。裁剪仅针对有保护垫的长数字零静音，不用噪声门切掉轻辅音。
- 自然、温柔、轻快、讲故事中文语气检查异常拖长，最多两个候选；睡前舒缓、自定义指令、混合字母/数字和不足8汉字的短句不硬套此检查。异常通过可识别的503错误返回，后台不会重复合成同一被拒绝的候选。
- 绘本原图与分页保留。跟书模式保留翻页停顿；连续模式可合并最多4个相邻短页、120字。章节、跳过页、长页及人工场景边界阻断跨页合成。
- 跨页音频使用本地Whisper small逐词时间戳、正文/同音声调匹配及真实低能量间隙定位，可靠时拆回逐页WAV；无法可靠对齐即逐页回退。音频PCM可完整拼回，导航、续读和离线下载仍使用原页对应的段ID。
- 试听与正式发布共用合成组缓存；可重新生成所选页相关组。新渲染、分段版本与旧缓存隔离，组清单、文件大小及哈希防止中断/损坏组被误用。

## 真实模型结果与边界

当前渲染指纹后缀：`render-2:b30d1c89f38db85a`。模型为固定revision的Qwen3-TTS 1.7B CustomVoice MLX 8bit。

原创句子“小兔子推开门，外面下雪了。它开心地笑了。”的两个生成版本：

| 倍率 | 版本0时长 | 版本1时长 |
| --- | ---: | ---: |
| 0.85 | 4.705875秒 | 5.176458秒 |
| 1.0 | 4.000000秒 | 4.400000秒 |
| 1.15 | 3.479625秒 | 3.826083秒 |

同机重复生成原始PCM逐字节相同，改变speed不影响基准生成；6条处理后音频的ASR关键内容检查通过。此前版本1曾生成9.2秒且实际有声部分异常拖长，守卫拒绝后第二候选为4.4秒。最终测量版本0含冷加载生成7.35秒，版本1含拒绝/重试生成13.78秒，不能把重试当成无额外延迟；这些数值不是手机首句端到端延迟。

- 中文三页样例：可靠定位门槛未满足，正确回退，合计4次合成（1次组合尝试+3页回退）。
- 英文三页Aiden样例：**只合成1次并成功对齐**，拆回3页。发布音频与试听逐字节相同，发布后读取不再调用模型。另有真实Aiden候选的切点1640/3880ms、PCM拼回一致证据。
- 对齐会保守回退，不能保证每本短页绘本都跨页合成成功。英文成功样例不能代替中文绘本整体听感验收。
- 音色指令、受限随机性和节奏守卫降低波动，不保证所有文本音色/字速完全相同；真实孩子常听内容、多音字、整体自然度仍需人工试听。此次没有连接物理手机做扬声器听感测试。
- 旧发布书与离线文件保持原声；应用新效果需更新服务和APK，并对图书重新试听、发布、下载新版本。

机器报告和原创WAV位于私有 `.artifacts/speech-consistency-verified/`，辅助对齐证据位于 `.artifacts/speech-consistency/aligned-acceptance/`，未提交音频和家庭运行数据。

## 验证中发现并处理的问题

1. 旧测试使用任意字节代替WAV；新时长/分组清单校验要求合法音频，改为可播放WAV夹具，并保留真实模型验证。
2. 主虚拟环境缺少锁文件已声明的 `qrcode==8.2`，安装该固定依赖后发布网站既有测试通过，未变更依赖锁。
3. 全量测试最初在断言通过后发生ONNX Runtime遥测线程退出崩溃（诊断堆栈为Microsoft Events/HttpResponseDecoder）。模型worker关闭不必要遥测后完整测试正常退出。
4. 模拟器原数据镜像空间不足，首次安装失败；随后使用单独的临时数据镜像完成测试，未清理用户原模拟器数据。
