# 单4B与2B文字/4B视觉比较（2026-09-23）

## 决策

当前保留文字 `qwen3.5:2b`、视觉 `qwen3.5:4b`。单4B确实减少驻留内存；修复教学问句过滤后，文字速度仍有差距，因此不切换生产模型，不合并权重。初次内容失败与修复后复测分开记录。此结论针对本机、现有模型版本与服务提示/过滤规则，不代表其他机器或4B模型普遍不适用。

## 安静模式修复后的复测

已修复明确英语教学开头问句及中文释义的误删，保留追加邀请过滤；清理后没有可朗读文字返回503且不写入成功会话历史。空行/纯标点不再占“两句回答”的名额。规则是有限的确定性处理，不声称能理解所有语言教学意图。

修复教学问句后，以8题×3轮、两模型交替先后，共48次实际推理复测；第8题改为小兔子英语介绍，全部请求实际调用模型。2B中位数0.75825秒/P95 0.9184秒，4B中位数1.3790秒/P95 1.6763秒，4B中位数增加0.62075秒。两边24/24返回非空内容，英语问候3/3恢复；这不是全部语义正确的声明。速度差距仍超过本轮参考，因此**继续保留双模型**，不再以已修复的空回答作为当前不切换理由。

证据 `compare-text-models-fixed.py`、`text-model-comparison-fixed.json/.log`；模型提示词和生成参数未改。该轮在最后的“空行不占句数”修订前完成，耗时只代表该实测版本；最终服务链路结果见《自测记录》顶部，不能将候选文字微基准冒充整机出声延迟。

`pytest ai-service/tests -q`最终107项通过（3.60秒、2条弃用提示），包含10组教学问句、普通追问、邀请、无内容、空行与不写错误历史的API回归；Ruff、OpenSpec严格校验、diff空白检查通过。生产模型配置和APK未改变，服务端后处理发生变化，原长测冻结不能用于该新版本。

## 方法与结果

使用实际 `/v1/turns` 路由、隔离临时数据库、相同生产提示词及生成参数，预热后交替先后顺序。每个模型8道问题×3轮，共24次接口请求。其中“讲故事”3次被本地资源路由接管，**排除模型延迟统计**，各剩21次真实模型调用。不是24道不同题，不是儿童实测，也不包含ASR/TTS、手机网络与播放时间。温度等生产参数未为了比较而修改；不把HTTP 200视为内容通过。

| 指标 | 2B文字 | 4B文字（与2B同时驻留） |
| --- | ---: | ---: |
| 真实模型调用 | 21 | 21 |
| 文字回答中位数 | 0.7483秒 | 1.2656秒 |
| P95（nearest-rank） | 0.9171秒 | 1.6700秒 |
| 生成速度中位数 | 43.30 token/s | 31.03 token/s |
| 空回答 | 0/21 | 3/21 |

中位数增加0.5173秒、约69.1%；P95增加0.7529秒。预先约定参考为中位数增加不超过约0.5秒、P95增加不超过1秒且内容不退步；本轮中位数处于边界附近，**内容退步是独立的不切换原因**。不能仅凭相对百分比或0.0173秒差异定案。

进一步卸载2B，仅保留4B，重复原7道问题，并用“小兔子英语介绍”替换被资源路由接管的故事请求，8题×3轮共24次真实调用，中位数1.3790秒/P95 1.6971秒。此总体包含不同第8题，不直接与上表总体相减。原7题同样出现3次空回答；复核证明不是两模型争抢内存导致该问题。完整问答见本地原始记录。

## 内存

同一项目Ollama `/api/ps` 的 `size_vram` 记录：2B为2,360,355,059字节，4B为3,144,910,109字节。两者共约5.13 GiB，仅4B约2.93 GiB，减少约2.20 GiB（43%）。这是模型运行时报告的驻留分配快照，不是整机总内存下降量，不包含语音识别、语音合成、服务和操作系统。只停止驻留，没有删除2B磁盘文件。

## 初次比较发现的问题与后续门槛（历史）

“用英语和我打个招呼，再告诉我中文意思”时，4B原始输出为 `Hello, how are you? 你好，你怎么样？`。现有安静模式删除多句回答中的问句，错误地连教学内容一起删除，最终返回空字符串。双模型比较3次、单4B复核3次均复现。这是服务后处理与候选输出的兼容问题，不能归因为4B不会英语；生产2B也存在同类输出触发的可能，应单独修复并回归。

另有教学用句的括号/解释被短句截断、2B没有遵循简单英语回答加法等现象；小样本不足以宣称任一模型开放问答全部正确。未因模型返回成功而认定质量通过。

下次切换前：修复安静模式保留明确请求的教学问句及空输出保护；按相同题集复测文字速度与内容；若满足切换条件，再切换角色配置、去重预热/安装校验并跑实际ASR→模型→TTS性能与华为链路，重新冻结长测。不得用缩短回答或剔除失败问答掩盖性能/质量变化。
