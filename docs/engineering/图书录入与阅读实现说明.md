# 图书录入与阅读实现说明

2026-09-23。本轮对应原始需求 R12—R21，源码及本批自动化回归已完成；华为录入UI和阅读控制分别42.774秒、207.664秒通过。测试夹具/真实硬件范围及尚未完成的家庭验收以《自测记录》和OpenSpec第8—10节为准。

## 录入与日常维护

家长手机进入“资源库”，创建图书草稿后，在资源编辑页填写名称、别名、版本、ISBN、作者、出版社、来源、语言和适龄信息。封面只用于识别图书，不能代替正文。

- 单页拍摄：使用“拍摄封面”或“拍摄书页”，先授权相机；取消拍摄不会修改书页。
- 连续拍摄：选择“连续拍摄书页”，每拍一张可继续拍摄，最后选择“导入已拍书页”。取消本批会删除尚未上传的临时照片。最多300张，拍摄顺序就是初始录入顺序。
- 批量选图：选择“批量选择书页图片”。顺序来自系统选择器，导入后必须核对；使用“向前移动”调整。单文件上限32MB，一本最多300页。
- 文字和PDF：使用“导入书页 / PDF / 文本”；TXT和Markdown以换页符分页面，长页按2万字符拆分，不用模型扩写。
- 单页修正：查看源图、修改原文，或者“重新识别本页”“顺时针旋转90°并识别”“重新拍摄替换本页”。成功重识别取消目标页的校对确认；其他页保留。失败不会拿空结果覆盖已有正文。

上传批次串行处理，每份素材完成后读取新草稿版本再上传下一份，避免自己制造版本冲突。“停止后续导入”会取消当前作业并停止后续上传，已处理页保留。网络中断且上传结果不确定时停止整批，刷新任务后再判断，不能盲目重传。PDF提取器每完成一页就输出结果；整批180秒超时时保留已完成页，其余位置标记失败，可单页补试。重拍失败的作业可从任务列表重试同一张新照片；原正文保留但需要重新确认。手机离开后，已提交到服务器的作业仍可查询；尚未提交的选择队列不会承诺跨进程恢复。

质量提示与正文分别保存：空白、完全相同正文、识别置信度较低、识别失败。另外，草稿详情会对同章相邻的明确印刷页码提示跳号、重复或逆序，保存后刷新；无页码和跨章不猜测。它们只是核对线索，不代表已识别出所有缺页、错字或复杂绘本阅读顺序。相同正文可能是原书有意重复，系统不会自动删页。没有可靠印刷页码时留空，界面仍显示录入位置。升级前旧导入工具曾自动填写顺序号，已有资源需由家长核对是否真是印刷页码；不自动改写历史发布快照。

保存正文、校对每页、确认完整/节选范围并试听后，才发布固定版本。修改正文、页序、声音或范围会要求重新试听；新导入路径都不会自动发布。

## 电脑目录导入

管理员把一本书放进数据目录的一个 `inbox` 子目录。例如：

```text
runtime/inbox/小兔绘本/
  cover.jpg
  001.jpg
  002.jpg
  010.jpg
```

在项目根目录执行：

```sh
ai-service/.venv/bin/robot-service --data runtime import-directory 小兔绘本 --title 小兔绘本
```

一目录生成一条新图书草稿；文件按自然数字顺序处理，`2`在`10`前。`cover`或`封面`命名的图片作为封面，最多一张。接受图片、PDF、TXT和Markdown；音频使用家长端导入。忽略Finder/Windows的`.DS_Store`、`Thumbs.db`、`desktop.ini`元数据；禁止绝对路径、越界、符号链接及子目录；不扫描整个磁盘，不删除原文件。重复执行会创建另一份草稿，不是自动同步命令。`inbox`原始收件文件不属于资源ZIP备份；完成入库的素材另存入`assets`并随资源备份。确认入库和备份后可自行清理收件目录。

输出包含资源ID、每个文件的作业状态与失败情况。处理失败不自动删除已成功导入的内容；在家长端搜索书名，核对正文、版次、页数、页序、语言和范围，再试听发布。命令与HTTP入口共用素材校验和入库代码，不启动第二个Web服务。

## 孩子的阅读流程

“读这本书”使用本次请求后的相机帧。唯一命中先报书名；同版本有有效进度时询问“接着上次读，还是从头开始读”。两候选以内朗读名称、版次和语言，可回答“第一本”“第二本”；候选更多时请补充ISBN或由家长选择。

候选说明说完后才接受选择；合成失败会清除候选。候选确认最多保留30秒，和当前会话绑定。取消、停止、新会话、超时或撤回会清理；播放前再次校验版本。确认期间发生换版则提示重新选择，不把旧进度应用到新正文。ISBN或明确版次优先于泛书名，精确命中的未发布版本不会被另一本可读同名书替代。

不可读原因分别提示：封面没看清、尚未入库、已录入但未发布、没有正文、已下架、相机未开启/无画面。OCR服务不可用单独说明；家庭服务无法连接走已有本地离线提示和诊断，不声称书未入库。未审核正文不返回机器人候选。

支持“从头读”“继续”“读第三页”“读第二章”“读第二章第三页”。正文按已发布文本和页面顺序播放。重复页码先请求章节；没有印刷页码的书按录入顺序定位并提前说明。缺失的页码/章节不猜测、不补写。整段原录音没有分段时间映射时，只能续播或从头播放，不能伪造分页定位。实体翻页不会自动改变播放位置。

节选开始前朗读家长填写的范围，随后才进入原文。范围说明不属于正文、不能成为正文进度；生成音频受相同版本和语音配置约束。完整离线下载包含说明音频，缺文件、缺哈希或旧节选缓存没有说明时拒绝冒充完整下载，需要重新下载。离线封面识别和自由语音选择仍依赖电脑在线；已下载资源可使用有限口令或下载目录。

## 工程接口与数据

| 位置 | 职责 |
| --- | --- |
| `imports.py` / `extract.py` | 校验素材、后台提取、页级错误、目标页替换、版本并发保护 |
| `inbox.py` / CLI | 受控目录的显式批量导入，复用素材服务，不自动发布 |
| `library.py` | 名称/ISBN/版次匹配、可读性原因、固定版本和独立节选说明 |
| `MainActivity.ResourceEditor` | 相机、连续拍摄、系统选图、串行上传、校对和维护界面 |
| `ReadingNavigation` | 确定性阅读指令与页码/章节定位，不调用大模型猜位置 |
| `RobotRuntime` | 有界候选确认、续读选择、版本复核、离线说明和正文播放 |

新增或扩展接口：

- `POST /v1/resources/{rid}/assets?purpose=pages&expectedVersion=N&targetPageId=...`：可选目标页用于重拍替换，只接受单张图片。
- `POST /v1/resources/{rid}/pages/{pageId}/extract`：请求体含 `expectedVersion`、`rotation`（0/90/180/270）。读取保存的原稿和源页，只更新目标页。
- `GET /v1/jobs/{jobId}`：查询单项状态，避免批量轮询依赖最近200条列表。
- `GET /v1/assets/{assetId}/page/{sourcePage}?rotation=90`：显示旋转后的源图，仅家长可读。
- `manifest.scopeNotice`：独立说明的ID与文本；音频走同版本 `/audio/scope-notice?revisionId=...`。

页面增加 `sourceRotation`、`extractionError`、`confidence`、`qualityWarnings`。作业增加 `options`，持久保存目标页、源页和旋转角度；重试携带原选项。数据库从schema 1自动迁移到2，只加作业字段；不认识的数据库版本拒绝启动。必须先停旧服务再升级，旧服务不能继续对迁移后的作业表写入。

回滚使用迁移前代码与数据库备份一起恢复，不能只切回schema 1代码。使用本文功能前检查新服务已重启，避免旧进程提供旧接口。发布和备份恢复仍保留原有人工审核、资源归属和删除墓碑保护。
