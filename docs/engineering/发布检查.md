# 发布检查

当前状态为开发预览，只有已记录证据的项目可以勾选。OpenSpec任务未全部通过前，不归档为“全部完成”。

真人、实体书、实物及家庭网络的实际执行与空白记录模板见[家庭实体验收执行表](家庭实体验收执行表.md)；模板不是已完成结果。

- [ ] 全部需求与实现/测试映射闭合，服务及Android定向测试、Lint与构建通过。
- [ ] 真机麦克风、AEC、相机新帧、后台释放、音频焦点、断网/重启与禁用时段逐项验收。
- [ ] 10本真实家庭样书、30次清晰封面和20次歧义/遮挡测试，中英文全文朗读人工核对。
- [ ] 目标儿童30次唤醒、5轮连续对话10组、播放中停止和2小时背景误唤醒测试。
- [ ] 4小时混合、24小时待机真实记录，温控、耗电、内存、延迟与失败率符合产品阈值。
- [ ] 安装/升级/回滚/备份/恢复演练成功；旧凭据、旧指令、撤回离线副本都不可复活。
- [ ] 自有源码MIT文件齐全；模型、AAR及其传递原生依赖的许可、署名、源码提供义务逐一核对。
- [ ] APK或模型包含GPL/LGPL等依赖时先完成对应源码与分发义务；不得仅附项目MIT就发布二进制。
- [ ] 确认Android release签名由维护者保管，不使用debug签名或公司签名，签名材料不入库。
- [ ] 开源内容不含家庭内容、儿童数据、运行数据库、连接码、恢复凭据、私钥、内网配置或实机日志。
- [ ] GitHub私密漏洞报告入口、维护者联系方式与支持范围设置完成。
- [ ] 生成源码/发行包清单、SHA256、第三方清单与版本说明；包含“已知限制/未验证平台”。

源码清单可运行 `ai-service/.venv/bin/python scripts/source_manifest.py` 生成；它记录未提交状态，不代表发行版本已确定，也不生成或上传公开发行包。

单一华为手机可以顺序验证双身份，不能据此声称两台手机同时远程管理已通过。无运动硬件时仅发布安全核心源码的实验性说明，不宣传真实机器人运动能力。
