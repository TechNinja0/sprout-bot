# 启蒙问答与故事提示词

2026-09-25。适用于本地文本问答与家长草稿试聊。

## 问题与调整

旧日常模板要求通常 40 字以内、追问时才展开，故事模板要求每次只讲一小段。服务另有普通回答 96 token、故事 160 token 的生成预算，以及回答只留两句、故事只留三句、最终截到 120 字的处理。因此，只把提示词改为“详细回答”仍然会丢失后面的解释或故事结局。

新模板位于 `ai-service/robot_service/data/default-prompts.json`，不改变字段或可用变量。

| 情境 | 默认表达方式 |
| --- | --- |
| 寒暄、确认、简单事实 | 一两句话；明确要求一句话时遵从 |
| 为什么、现象原理 | 通常 120—220 字：直接答案、两三步因果、必要的生活观察、自然收尾 |
| 明确要求详细 | 可到 300—450 字，增加解释而非重复 |
| 原创故事 | 通常 350—500 字，角色目标、困难、尝试、解决与完整结局 |
| 英语启蒙 | 一个词或表达、中文含义、生活情境；不把中文科普自动变成英语课 |
| 看图识物 | 继续依据当前画面和结构化观察，保留原视觉输出边界 |

以上字数是模型的表达目标，不是强制最低字数。词句按年龄与表达设置调整；安静模式约束主动追问，不再要求把答案压短。科学问题优先描述真实过程，只有比喻准确时才使用；不确定时说明，不把拟人化或想象作为原因。模板中的植物与阳光示例用于示范因果讲法。

## 参考与取舍

- [Khan Academy 的 Khanmigo 提示词方法](https://blog.khanacademy.org/khan-academys-7-step-approach-to-prompt-engineering-for-khanmigo/)：参考适应学习者、联系兴趣、用样例和实际对话评估提示词的方法。
- [Khanmigo 故事创作](https://blog.khanacademy.org/encouraging-your-childs-creativity-how-to-write-a-short-story-khanmigo-kp/)：参考角色、情境、冲突和开头—经过—结尾的完整故事结构。
- [Gemini Guided Learning](https://blog.google/products-and-platforms/products/education/guided-learning/)：参考分步讲解、按理解程度调整解释的方式。

这些是公开产品设计说明，不是竞品实测或其内部提示词。当前产品以幼儿语音陪伴为主，所以孩子提问时先解释，避免照搬作业辅导产品不断反问的方式；先完成故事，也不强制进入共同创作流程。保留原有主动互动、原创故事授权和书库原文规则。

## 服务处理与兼容

`reply_policy.py` 统一文本生成预算为 1024 token、上下文 8192 token。儿童问答和家长试聊都使用这一预算；视觉请求维持原预算。模板末尾追加本轮详略要求，区分明确简短、故事和英语请求，减少小模型同时处理多种场景规则时的干扰。普通文本取消前两句/前三句限制，最多 600 字，异常超长时优先收在完整句末。原创标识计入 600 字。

600 字与现有 `Speak` 校验和 Android 朗读入口一致；Android 已经按句预取、播放并检查取消状态，不需要为此次服务调整更新 APK。家长试聊组合日常规则与所选专项规则，日常页直接请求故事也会加入故事模板。试聊仍然是独立调试，不代表开启儿童端原创故事权限。

生成预算是上限，不是要求每次用完。回答更长可能增加文本生成和总播放时间，保留原请求超时，不通过无限放大超时掩盖性能问题。句末裁剪只是异常输出兜底，不保证模型在超额情况下仍有完整故事结局。

## 生效方式

更新服务代码后重启家庭服务。未保存自定义提示词的配置会读取新默认值；已保存的模板继续保留，包括旧默认模板，避免覆盖家长修改或破坏历史版本。

已有设备：家长管理 → AI 提示词，分别选择“日常”“英语”“故事”，点击“恢复本项默认”，最后“保存并应用”，待机器人确认后开启新会话。原会话保持其提示词快照，最长在闲置十分钟后重新读取配置。机器人离线时无法完成配置确认。

儿童端“讲个故事”仍优先使用书库；原创需要已有设置允许并明确请求“编一个故事”。此次不自动开启原创故事、主动互动或对话保存。

## 验证

定向回归覆盖完整科普和故事经过输出处理、会话上下文及朗读参数校验后保持完整，安静模式去掉继续邀请、故事内部对话保留、超长句末处理，以及试聊模板组合。继续运行既有权限、书库分流、视觉和配置快照回归。

真实模型抽查脚本：

```sh
PYTHONPATH=ai-service ai-service/.venv/bin/python scripts/prompt_smoke.py
```

脚本通过真实 `/v1/turns` 路径调用本地模型，使用临时数据库和虚构问题，不修改家庭数据。输出 `.artifacts/prompt-quality/smoke.json`，保留回答、长度、耗时和状态。题目包含下雨、天空颜色、月亮、昼夜、融冰、影子等未在最终模板中直接给出答案的问题、追问、简短请求、英语和完整故事。

长度检查通过不能证明事实正确，也不能替代目标儿童的理解度、语音听感和设备端长时体验验收。当前 2B 本地模型仍需要逐条审阅；提示词不能保证所有知识回答正确。
