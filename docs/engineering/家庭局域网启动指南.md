# 家庭局域网启动指南（macOS）

机器人手机通过 Wi-Fi 直接连接电脑的 HTTPS 服务，不需要 USB 数据线、ADB reverse 或公网服务器。电脑和手机必须能在局域网互通。Ollama 只监听电脑本机 `127.0.0.1:11435`；只有家庭 HTTPS 服务监听局域网。

## 已配置电脑的日常操作

在项目根目录打开终端：

```bash
bash scripts/home_service.sh start
bash scripts/home_service.sh status
```

`start` 可重复执行，不会重复创建进程。它启动 Ollama 和家庭 HTTPS 服务；进程启动后还需要等待模型预热。APP、启动脚本和命令行的默认家庭端口统一为 **8766**，不会在每次启动时自动变更。通常只需在 APP 中填写电脑 IP；如果手动更改服务端口，APP 也应填写相同端口。

```bash
# 重启家庭 HTTPS 服务（不重启正常运行的 Ollama）
bash scripts/home_service.sh restart

# 停止本次登录会话的服务
bash scripts/home_service.sh stop

# 查看服务日志
tail -f runtime/logs/org.familyrobot.service.log
```

本机使用 `~/Library/LaunchAgents/org.familyrobot.service.plist` 和 `org.familyrobot.ollama.plist` 托管服务：关闭终端仍运行，异常退出后重启，用户登录 macOS 后自动启动。它不是开机未登录即可运行的系统级服务。服务运行时 `caffeinate -i -s` 防止空闲睡眠，并在接通电源时请求避免系统睡眠；请保持电脑开机，笔记本不要合盖。

`status` 只显示进程状态。模型是否预热完成，请在 App 的“检查与调试”中确认；健康接口 `/health` 的 `modelWarmup` 为 `ready` 才代表预热完成。

## 查看电脑局域网 IP

```bash
networksetup -listallhardwareports
# 找到 Wi-Fi 对应的 Device，例如 en1，再执行：
ipconfig getifaddr en1
```

手机保存的服务地址格式为 `https://<电脑局域网IP>:8766`。路由器最好为电脑保留固定 DHCP 地址。更换 Wi-Fi 或 IP 后，原地址不会自动更新。家庭路由器无需做公网端口转发。

## 新电脑的前台启动方式

先按《工程维护手册》安装 Python 环境、本地模型和 TTS。如果是全新的数据目录，必须先初始化证书和服务身份：

```bash
ai-service/.venv/bin/robot-service --data runtime init --host <电脑局域网IP> --port 8766
```

以下两条命令分别在两个终端保持运行：

```bash
# 终端一：默认从 .tools/ollama/ollama 启动，也可指定实际安装路径
ROBOT_OLLAMA=/实际路径/ollama bash scripts/run_ollama.sh

# 终端二：Apple Silicon 的 MLX ASR、Qwen3-MLX TTS 和启动预热
bash scripts/run_home_service.sh
```

前台方式与后台托管方式二选一，同一端口不要重复启动。`run_home_service.sh` 默认监听 `0.0.0.0:8766`，可用 `ROBOT_BIND`、`ROBOT_PORT` 覆盖；`0.0.0.0` 是监听地址，不能填进手机连接材料。非 Apple Silicon 平台需要按维护手册显式选择适用的 ASR/TTS 后端。

首次连接新机器人时，在 App 选择“小伙伴”身份，填写电脑局域网 IP（默认端口 8766），连接并设置管理 PIN 即可，无需电脑端确认。家长手机扫描小伙伴管理页生成的配对二维码。

如需使用备用文件导入方式，服务运行后生成两分钟有效的连接文件：

```bash
ai-service/.venv/bin/robot-service --data runtime invite --host <电脑局域网IP> --port 8766
```

把 `runtime/connection.json` 通过受信方式传到手机，在首次设置中导入、验证并设置管理 PIN；材料过期后用 `invite --host <电脑局域网IP> --port 8766` 重发。已有家庭身份不要为了换地址重新登记；证书、服务 ID、设备令牌和家庭数据应保留。App 校验证书指纹和服务 ID，不能跳过这些校验。
