| R21 从头、定位与跨次续读 | 暂停/继续/上下页章已有；缺从头、任意明确页码/章定位、重复页码澄清 | 有界确定性指令解析；无印刷页码用入库顺序并说明；重复标签先确认章节；进度必须同版 |
| R22 不跟随实体翻页 | 无持续跟页，媒体不延长相机输入时间 | 保留相机超时和下一页规则 |
| R23 固定声音与完整离线 | 已有音色快照、完整下载/哈希/真实换声回归 | 新节选提示纳入同版校验，不混用旧正文/新声音 |
| R24 草稿与发布并存 | 普通改版/历史撤回修复已有真机证据 | 新导入/确认/定位不得改写当前有效阅读快照 |
| R25 清单与通用资源 | 已有，清单不复制正文、访问前校验 | 新阅读流程保留清单衔接与原音频播放 |
| R26 撤回、删除、恢复 | 已有精确撤销版本、删除清理和恢复草稿规则 | 待确认书籍在撤回后不可启动；迟到OCR/合成不可复活内容 |

推荐实现决策：

- 图书交互由有界会话状态处理，保存候选ID/版本和允许的回答；不依赖聊天模型猜测孩子选择了哪本书。最多两候选，更多候选请补拍书名/ISBN。
- 单页处理继续使用已有版本并发校验。页旋转记录在来源元数据；重识别只更新目标页且撤销其校对状态，不覆盖其他页或吞掉家长的新修改。
- OCR问题提示与原文分开保存；空白和低置信不等于自动判错，发布仍由家长审核。部分失败可以单页重试。
- 目录导入由电脑管理员显式执行，限制在服务收件目录、拒绝越界与符号链接，保留原文件。不启动全盘扫描或自动发布。
- 节选范围提示与正文分开标识，按资源版本/语音渲染配置生成并纳入离线完整性。它不能冒充原书正文。
- 新能力合并后统一做服务、核心规则、Android构建和华为流程回归，再冻结最终版本做长测。所有真实儿童、家庭样书和环境验收仍独立记录。
