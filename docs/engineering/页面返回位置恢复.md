# 页面返回位置恢复（2026-09-26）

## 原因与修复

旧公共页面通过 `remember(title) { ScrollState(0) }` 创建滚动状态。切换标题或从 composition 移除后重新进入，会从零创建；只把它改成 `rememberSaveable` 也不足以跨已移除的页面保存。部分列表返回时还会重新请求数据，加载占位的短高度会将偏移压到零。

`PageNavigationScope` 在当前身份和家庭连接的导航范围内保存轻量浏览状态：

- 公共 `Page` 使用稳定 `pageKey` 保存滚动偏移。图书详情按图书ID，校对按图书ID、步骤、子页面和书页ID隔离；知识、清单、计划、会话详情也各有内容标识。改书页顺序不会把另一页的位置带过来。
- 加载或业务操作暂时隐藏内容时暂停记录偏移；内容就绪并完成布局后再恢复。返回不是重新滚到顶部。数据实际减少时，偏移限制到新的可滚动范围。
- 资源库搜索词、筛选、已下载集合，以及知识库搜索/筛选、记录类型、偏好筛选保留。公共展开说明也按页面保存，避免返回时内容高度突然收缩。
- 仍保留必要的数据刷新，以便显示修改、发布或删除后的结果；没有缓存网络任务，也不自动保存未提交的业务草稿。
- 调试会话只在消息数量改变时滚到底部；打开记录再返回或键盘改变高度，不再主动把阅读位置推到底部。
- 身份或家庭连接改变时隔离状态。Bundle 仅含偏移和少量界面字符串，不含凭据、录音和书籍正文。

这里恢复的是滚动偏移，不是列表项锚点；若其他设备在列表前面插入或删除项目，可见项目可能改变。此修复不改变发布或离线版本的读取规则。

## 验证方式

为避免同时进行的“陪伴对话记录”修改混入本次提交，将暂存的导航改动导出到 `/tmp/robot-navigation-verify.nt9eni`，只链接现有模型资源和本地 AAR，独立构建与测试。

构建使用 JDK17 和 Android SDK36，执行：

```sh
android-app/gradlew -p android-app :core:test :app:testDebugUnitTest \
  :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug --offline --console=plain
```

独立构建结果：`BUILD SUCCESSFUL`；core 53项、app 4项单元测试通过；Lint 0错误、12警告。`ruff check scripts/navigation_ui_fixture.py`、`ruff format --check scripts/navigation_ui_fixture.py` 和 `git diff --cached --check` 均通过。

设备测试使用临时数据盘的 Android16 模拟器 `emulator-5580`，独立安装上述两个 APK；不修改用户原模拟器数据。真实页面流程通过以下 fixture 使用隔离 HTTPS 服务（8881端口、25本测试书，每本40页），不连接家庭运行数据：

```sh

adb -s emulator-5580 shell run-as com.robot.app cp /data/local/tmp/navigation-connection.json files/navigation-connection.json
adb -s emulator-5580 shell am instrument -w -e class org.familyrobot.app.PageNavigationStateTest,org.familyrobot.app.NavigationReturnFlowTest,org.familyrobot.app.BookPageOrderTest,org.familyrobot.app.SpeechReadingTest com.robot.app.test/androidx.test.runner.AndroidJUnitRunner
```

最终设备结果：`OK (16 tests)`，96.27秒。

覆盖内容：异步加载后恢复、刷新临时隐藏内容、数据变短、同标题不同书页、身份隔离、Bundle保存恢复；真实家长端的资源库搜索筛选→详情→图书校对→返回，以及家长设置和机器人PIN管理设置的子页返回。按实际返回前后相同条目的屏幕坐标断言，而非仅检查页面标题。另回归长按排序与试听分组。

未连接实体手机，也未做家庭设备的长期运行验收。测试中修正了测试工具初始状态等待、输入框定位以及模拟器全屏引导处理；这些不是业务功能修改。
