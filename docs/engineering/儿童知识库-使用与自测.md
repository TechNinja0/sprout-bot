# 儿童知识库：使用与自测

日期：2026-09-25。设计依据见 [产品技术与交互设计](../design/儿童知识库-产品技术与交互设计.md)。

## 使用

1. 更新家庭服务代码并重启服务，首次启动自动加入 30 条附来源的内置百科；再安装同版本 Android App。
2. 家长首页或设置 → 知识库。点击内置问题即可纠错；也可以添加“儿童百科”或“家庭知识”。
3. 填写核心问题与讲解。可以展开“相似问法与不同详略”，增加孩子自己的问法和简短、详细讲解。百科发布需要来源说明。
4. “保存草稿”仅保存编辑；“用当前草稿试问”不影响孩子。点击“预览发布”，核对表达、年龄、来源并勾选确认，再“发布并启用”。
5. “试问知识库”仅查询当前已启用、适龄的内容。停用立即移出检索，删除需要确认。发布有冲突时保留本机输入，返回列表重新读取后整理，避免覆盖另一位家长的修改。
6. 家庭内的机器人共用知识库，按各自年龄筛选。孩子可说“再详细讲讲”“简单一点”；近似问题先确认，回答“是的”后再讲对应知识。

现有对话记录设置继续生效；管理试问不写入孩子的偏好。备份包含知识与删除标记，恢复为待审核草稿。App 恢复后立即刷新索引；电脑 CLI 恢复应停服进行，随后启动服务重建索引。

首版不是任意资料的语义问答系统：直接回答依赖核心问题或相似问法的明确匹配。未收录的明确科普问题会说明没有可靠讲解，普通聊天和故事保留模型路径。默认 30 条覆盖有限，可由家长逐步扩充。

结果：152 项测试通过；Ruff、契约生成和差异检查通过。已有 Starlette/httpx 依赖弃用提示 2 条，不影响本次结果。

新增 11 项知识库测试覆盖：30 条内置内容及别名的精确命中、家长/儿童权限、草稿不泄漏、预览、年龄、简短与详细追问、发布及停用删除、重启墓碑、并发版本冲突、备份恢复、重复知识不任意选答案、未知问题降级、保留数字/否定限定、澄清确认、清除旧上下文与取消生成中的旧回答。关闭可用模型槽和禁止 HTTP 模型调用的情况下，知识直答仍通过；检索禁止读取数据库的断言通过。

## 性能

```sh
ROBOT_PREPARE_AUDIO=0 ROBOT_PRELOAD_MODELS=0 ai-service/.venv/bin/python scripts/knowledge_smoke.py
```

隔离临时库，30 条真实预设 + 970 条合成家庭知识；每类查询 600 次，接口 100 次。结果文件：`.artifacts/knowledge/performance.json`。

| 项目 | p95 |
| --- | ---: |
| 精确问题 | 0.003 ms |
| 别名命中 | 0.0034 ms |
| 未命中 | 0.0051 ms |
| 近似候选 | 1.2824 ms |
| 普通寒暄的检索开销 | 0.0035 ms |
| 进程内 `/v1/turns` 完整请求 | 6.5161 ms |

索引构建 7.704 ms。所有检索类别低于目标 p95 10 ms；近似扩展另设 4 ms 计算预算。以上是本机测量，不含 Wi-Fi、语音识别、TTS、手机播放时间，也不是硬件无关的上限。
