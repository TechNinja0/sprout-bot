# 资源库建立与图书维护指南

版本 v1.4，2026-09-22。本文保留当时规划中的家长使用流程，后续已开始实现；其中界面名称和规划能力不能直接作为当前操作说明。实际使用请读 [家长与孩子使用手册](12-家长与孩子使用手册.md)，完成情况见 [自测记录](engineering/自测记录.md)。产品规则见 [PRD 第 9 节](01-产品需求文档.md)，实现设计见 [技术方案第 10 节](02-技术方案.md)。

## 1 这次补全了什么

此前文档只说明了内容导入、审核和播放，没有完整定义纸质图书如何转文字、如何按页纠错、封面怎样对应某个版本，以及后续如何维护。本轮把它们连起来：

**家长录入封面和书页 → 电脑识别文字 → 家长对照校对 → 发布图书 → 孩子展示封面并提出朗读请求 → 找到已录入版本 → 按审核正文朗读。**

封面用来找书，整本正文来自事先入库的内容。只拍一张封面，机器人无法因此获得你手里那本书的真实全文。

## 2 资源库和知识库的关系

| 层次 | 保存什么 | 家长如何维护 |
| --- | --- | --- |
| 原始素材 | 封面、书页照片、PDF、文字稿、儿歌录音 | 添加、补页、替换错误图片、保留来源 |
| 审核内容 | 书名与别名、版本、章节、页序、正文、语言和标签 | 对照原稿纠错、排序、审核、发布 |
| 派生内容 | 合成音频、下载清单、封面/文字检索索引 | 由系统根据发布版本生成；显示进度和失败原因 |

家长主要维护前两层。改正文后，系统自动标记受影响的音频和索引需要更新，不要求家长手动操作数据库或向量文件。孩子的个人记忆另行管理，不与书库混在一起。

## 3 第一次怎么建库

1. 先完成两端与家庭电脑的连接和绑定，进入家长端“资源库”。
2. 选择“图书 → 添加图书”，拍摄或选择封面，输入书名；补充口语别名、语言、年龄/英语难度和版次。ISBN 可不填，同名不同版本要能区分。
3. 添加内页照片或 PDF，或者直接粘贴/导入已有 TXT、Markdown 文字。封面与内页分开标记，不把封面、目录、页码全部自动混入正文。
4. 等待电脑提取/OCR。查看总页数与处理进度；手机离开页面后任务保留，失败的页可以单独重拍或重试。
5. 打开校对页，左/上侧原稿、右/下侧文字，按手机屏幕尺寸切换。检查错字、标点、缺页、重复页和阅读顺序；有多段文字的绘本尤其要确认先后。
6. 设置朗读范围、章节和页码映射。无文字的页可以跳过，或由家长另写讲述稿并标明来源。没有录完的书先存草稿；只发布部分时明确标记节选。
7. 选择朗读声音、试听，确认正文后发布；发布状态、音频生成状态和机器人下载状态分别展示。
8. 将常读书下载到机器人。整本下载完成才显示整本离线可读；也可明确只下载某章节。

建议先拿两三本书验证整套流程，再批量处理其余书籍。这里没有自动替你扫描实体书，也没有预装任何商业书库。

电脑批量录入可以把封面、内页和元数据交给受控导入目录/导入工具，系统生成图书草稿；家长手机仍可查看、补充与发布。不能把素材扔进文件夹就默认孩子已经能点播。

## 4 孩子怎么使用

孩子说“昵称，读这本书”，把封面朝向机器人。机器人识别可见书名等信息并查家庭图书库，唯一匹配时说出书名再开始；有上次进度时询问继续还是从头读。

如果同名书有两个版本，机器人会询问，或请孩子展示更清楚的封面/背面信息；没有找到时说“这本书还没有放进我的书架，请家长帮忙添加”。它不能凭大模型记忆编造原书，也不会自动去网络下载全文。

开始后可以说“暂停”“继续”“下一页”“上一页”“从头读”“休息吧”。首次支持顺序朗读和口头翻页；孩子翻实体书不会自动改变朗读位置。长读时摄像头按既有规则关闭，不要求孩子一直举着书。

机器人仍遵守作息和使用限额。没有网络或电脑关机时，可以播放已经下载的内容，但首版不承诺在手机本地识别封面；离线入口为已验证的有限口令和下载目录。

## 5 后续维护怎么操作

| 想做的事情 | 家长操作 | 系统需要完成的事情 |
| --- | --- | --- |
| 加一本新书 | 图书 → 添加 → 导入 → 校对 → 发布 | 创建独立资源，建标题/封面索引并准备音频 |
| 修正错字或读音 | 详情 → 编辑正文/读音 → 保存草稿 → 试听 → 发布新版 | 更新相关段落音频与检索；旧版进度不直接套新偏移 |
| 补页或重排 | 编辑页列表，补拍/拖动排序，重新校对 | 保持页来源关系，重建朗读清单；不能漏段重段 |
| 改称呼或分类 | 修改别名、语言、主题、年龄和难度 | 下次可以按新名字找书；保持资源身份不变 |
| 更新封面或增加封面版本 | 详情 → 封面 → 添加/替换 | 更新检索材料；不同正文版次不能只换封面掩盖 |
| 换朗读声音 | 选择声音并试听，生成新音频 | 原文不变；正在读的声音不半途跳变，下载提示更新 |
| 暂时不让孩子读 | 下架 | 在线停止并禁止点播，原稿留存可再审核上架 |
| 彻底删除 | 删除并确认范围 | 撤销正文和音频访问、清索引与引用；离线设备显示待清理 |
| 换电脑或留备份 | 资源库 → 导出/备份，恢复时校验 | 保存素材、正文、版本、页序与来源；索引可重建，发布需核验 |

资源列表应能按“草稿、待校对、已发布、生成失败、下载中、已离线、已下架、待清理”筛选；这些状态有些可以并存，例如旧版已发布、新版待校对。详情显示最近修改、版本、审核人和设备同步状态，不能只给一个模糊的“处理完成”。

发现某页内容有误需要立刻停止使用时，先下架旧版，再修正文、试听和发布。普通修订可以让当前旧版阅读完成，新一次阅读再切换；页面需要把两种行为说明白。

离线机器人无法收到即时撤回，家长端要显示这个事实；需要立即停止时在机器人本地操作。重连后先同步下架/删除记录，再更新可读目录。

## 6 其他资源也统一管理

图书、故事、儿歌和英语内容共用搜索、审核、发布、收藏、下架、删除、下载及备份操作。不同类型保留自己的编辑字段：

- 图书：封面、章节、页序、正文、版本、阅读进度。
- 独立故事：正文或原录音、主题、时长、合成声音；不必伪造页码。
- 儿歌：原录音、语言、时长、可选歌词，保留原演唱声音。发布时必须上传实际音频；仅有歌词不能发布为儿歌，普通 TTS 不提供演唱能力。
- 英语内容：实际资源类型加英语级别、语言/口音、可选中文解释；英文图书仍是一条图书资源。

播放清单引用资源，便于组合“睡前故事”“英文磨耳朵”等安排；引用的资源被下架或删除后，清单也不能继续访问旧版本。默认不自动播放，新内容不会因为刚发布就打断孩子。

## 7 发布前和维护时检查什么

每次发布确认封面对应正确版本、页序正确、正文已校对、完整/节选范围准确，并试听开头、分页处、专名/多音字和结尾。对英文书重点检查发音和语言切换，不能仅因 OCR 显示有文字就认为识别正确。

新增资源后先在家长陪同下试一次“看封面—选书—朗读—叫停”；重名书检查消歧。备份至少在大批量录入或重要修改后执行一次，恢复时先核对列表、页数与发布状态。固定收藏和原稿不能因磁盘不足被静默删除。

尚待实施选定：目标设备、OCR 引擎、支持语言的识别质量、单本页数/文件大小上限、TTS 音色和备份保存周期。它们不影响先确定以上产品流程，但不能在实测前承诺扫描准确率和处理速度。
